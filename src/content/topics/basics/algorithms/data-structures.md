**データ構造** とは、データを効率よく格納・操作するための形式です。データの追加・削除・参照のどれを速くしたいかによって、適したデータ構造が変わります。

## 仕組み

### 配列

同じ型のデータを **連続した領域** に並べ、添字（インデックス）で要素を指定します。

- 添字による参照は O(1) で高速
- 途中への挿入・削除は、後ろの要素をずらす必要があり O(n)
- 2次元配列は行・列の 2 つの添字で要素を指定します

### 連結リスト（リスト）

各要素（ノード）が **データと次の要素へのポインタ** を持ち、ポインタをたどってつながる構造です。

| 種類 | 特徴 |
| --- | --- |
| 単方向リスト | 次の要素へのポインタのみを持つ |
| 双方向リスト | 次と前の要素へのポインタを持ち、逆方向にもたどれる |
| 環状リスト | 末尾の要素が先頭を指す |

- 挿入・削除はポインタを付け替えるだけでよい（位置が分かっていれば O(1)）
- 特定の位置の要素を参照するには先頭からたどる必要があり O(n)

### スタックとキュー

| 構造 | 取り出し順 | 操作 | 主な用途 |
| --- | --- | --- | --- |
| スタック | **後入れ先出し（LIFO）** | push（積む）/ pop（取り出す） | 関数呼出しの戻り先管理、式の評価（逆ポーランド記法）、深さ優先探索 |
| キュー | **先入れ先出し（FIFO）** | enqueue（追加）/ dequeue（取り出す） | 処理待ち行列、印刷待ち、幅優先探索 |

### 木構造

親子関係で階層的につながった構造です。最上位の要素を **根**、子を持たない要素を **葉** といいます。

| 種類 | 特徴 |
| --- | --- |
| 二分木 | 各節点の子が最大 2 つ |
| 完全二分木 | 葉以外の段がすべて埋まり、最下段は左から詰めて並ぶ二分木 |
| 二分探索木 | どの節点でも「左部分木の値 < 節点の値 < 右部分木の値」が成り立つ |
| ヒープ | 完全二分木で、どの節点でも「親 ≥ 子」（最大ヒープ）または「親 ≤ 子」（最小ヒープ）が成り立つ |
| B木 | 1 つの節点に複数のキーを持つ多分木。データベースの索引などに使われる |

二分探索木は、木の形が偏らず平衡していれば探索が O(log n) ですが、昇順に値を挿入するなどして偏ると、リストと同じ O(n) になります。

### 二分木の走査（なぞり方）

| 方法 | 順序 |
| --- | --- |
| 先行順（行きがけ順） | 節点 → 左部分木 → 右部分木 |
| 中間順（通りがけ順） | 左部分木 → 節点 → 右部分木 |
| 後行順（帰りがけ順） | 左部分木 → 右部分木 → 節点 |

二分探索木を中間順でなぞると、値が **昇順** に取り出せます。

## 例題

**例題1** 空のスタックに対して、push(1)、push(2)、pop()、push(3)、push(4)、pop()、pop() の順で操作した。最後に取り出された値は何か。

**解き方**: 状態を追います（左が底）。

```
push(1) → [1]
push(2) → [1, 2]
pop()   → 2 を取り出す → [1]
push(3) → [1, 3]
push(4) → [1, 3, 4]
pop()   → 4 を取り出す → [1, 3]
pop()   → 3 を取り出す → [1]
```

答え: **3**

**例題2** 同じ操作をキューで行った場合（push を enqueue、pop を dequeue と読み替える）、最後に取り出された値は何か。

**解き方**

```
enqueue(1), enqueue(2) → [1, 2]
dequeue() → 1 → [2]
enqueue(3), enqueue(4) → [2, 3, 4]
dequeue() → 2 → [3, 4]
dequeue() → 3 → [4]
```

答え: **3**（取り出し順は 1, 2, 3）

**例題3** 次の二分木を中間順になぞった順序を答えなさい。根が 8、その左の子が 3（3 の左の子 1、右の子 6）、根の右の子が 10。

**解き方**: 左部分木（1 → 3 → 6）→ 根 8 → 右部分木 10 の順で **1, 3, 6, 8, 10**。この木は二分探索木なので昇順になります。

## 試験対策のポイント

- **ITパスポート**: スタック（LIFO）とキュー（FIFO）の違い、配列とリストの特徴の違いが中心です。
- **基本情報技術者**: スタック・キューの操作のトレース、リストのポインタ付け替え、二分探索木・ヒープの性質がよく出ます。科目Bでは配列やリストを使った擬似言語のプログラムが頻出です。
- **応用情報技術者**: 木の走査順序、ヒープへの要素追加・削除後の形、データ構造の選択理由など、より踏み込んだ理解が問われます。
