コンピュータは、あらゆる情報を 0 と 1 の組合せ（ビット列）で表し、論理演算の組合せで計算を行い、手順（アルゴリズム）に従って処理を進めます。
この分野では、ハードウェアやソフトウェアの仕組みを学ぶ前提となる「数の表し方」「論理の組み立て方」「処理手順の考え方」を学びます。

## この分野で学ぶこと

| 項目 | 内容 | 主に関わる試験 |
| --- | --- | --- |
| 数値表現 | 2進数・16進数と基数変換、補数による負数表現、浮動小数点数と誤差 | IP（基数変換）/ FE / AP |
| 論理演算と論理回路 | AND・OR・NOT・XOR、真理値表、ド・モルガンの法則、半加算器 | IP / FE / AP |
| アルゴリズムとデータ構造 | 配列・リスト・スタック・キュー・木、探索・整列と計算量 | IP（データ構造の基本）/ FE / AP |
| 確率と統計 | 場合の数・確率、平均・分散・標準偏差、正規分布、相関・回帰 | IP / FE / AP |
| 情報理論と符号化 | 情報量、ハフマン符号、パリティ・CRC・ハミング符号による誤り検出・訂正 | IP（圧縮の基本）/ FE / AP |
| プログラミング | 擬似言語の読み方、再帰、プログラム言語と言語処理系 | IP / FE / AP |

## 学ぶ順序

1. **数値表現** … まず 2進数と基数変換に慣れます。補数・浮動小数点数はその応用です。
2. **論理演算と論理回路** … ビット単位の演算は数値表現と表裏一体です。半加算器は「2進数の足し算を論理回路で実現する」ことを示し、数値表現とつながります。
3. **アルゴリズムとデータ構造** … データをどう並べて持つか（データ構造）と、それをどう処理するか（探索・整列）を学びます。計算量の考え方は性能評価全般の基礎になります。
4. **確率と統計／情報理論と符号化** … 数学的な道具立てです。確率は待ち行列や信頼性の計算に、符号化は通信の誤り検出やデータ圧縮につながります。
5. **プログラミング** … 擬似言語でアルゴリズムを読み書きする力をつけます。基本情報の科目Bの中心です。

## 他分野とのつながり

- 数値表現・論理回路は、CPU やメモリの仕組み（コンピュータシステム分野）を理解する前提になります。
- 基本情報技術者試験の科目B（アルゴリズムとプログラミング）では、データ構造と探索・整列の理解がそのまま問われます。

## 試験対策のポイント

- **ITパスポート**: 2進数と10進数の変換、論理演算の真理値表、スタックとキューの違いなど、基本の用語と簡単な計算が中心です。
- **基本情報技術者**: 補数・浮動小数点数・計算量など、計算やトレースを伴う問題が科目Aで頻出です。
- **応用情報技術者**: 同じテーマがより複雑な条件（誤差の発生原因の判別、アルゴリズムの比較など）で問われます。
