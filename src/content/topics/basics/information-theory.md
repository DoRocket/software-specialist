**情報理論** は、情報の量を確率を使って数値化する理論です。その考え方を基に、データを短く表す **情報源符号化（データ圧縮）** と、
伝送・記録中の誤りを見つけたり直したりする **通信路符号化（誤り検出・訂正）** が設計されています。

## 情報量

確率 P で起こる事象を知ったときに得られる **情報量** は次の式で表し、単位はビットです。

$$
I = -\log_2 P \quad \left(= \log_2 \frac{1}{P}\right)
$$

- 起こりにくい（P が小さい）事象ほど情報量が大きい。確率 $\dfrac{1}{8}$ の事象の情報量は $\log_2 8 = 3$ ビット
- 確率 1（必ず起こる）の事象の情報量は 0
- 各事象の情報量を確率で重み付けした平均を **平均情報量（エントロピー）** $H = -\sum P \times \log_2 P$ といい、1記号あたりの平均符号長の理論的な下限になります

## 可変長符号とハフマン符号

すべての記号を同じ長さで表す **固定長符号** に対し、出現頻度の高い記号に短い符号、低い記号に長い符号を割り当てるのが **可変長符号** です。
可変長符号を区切り記号なしで一意に復号するには、どの符号語も他の符号語の先頭部分（接頭語）にならないこと（**接頭語条件**）が必要です。

**ハフマン符号** は、次の手順で木を作って符号を決めます。

1. 出現確率の小さい 2 つを選び、それらを子とする節を作る（確率は 2 つの和）
2. 節が 1 つになるまで 1 を繰り返す
3. 根から各記号まで、枝に 0 / 1 を割り当てて符号とする

**ランレングス法** は「同じ値が何個続くか」で表す圧縮方式で、同じ値の連続が多いデータに有効です。

## 誤り検出・訂正

| 方式 | 仕組み | 能力 |
| --- | --- | --- |
| パリティチェック | 1 の個数が偶数（偶数パリティ）または奇数（奇数パリティ）になるよう 1 ビット付加 | 奇数個のビット誤りを検出。訂正はできない |
| 水平垂直パリティ | データを表状に並べ、行と列の両方にパリティを付ける | 1 ビットの誤りなら位置を特定して訂正できる |
| CRC（巡回冗長検査） | データを生成多項式で割った余り（2を法とする割り算）を付加し、受信側で同じ計算をして検査 | 連続したビット誤り（バースト誤り）の検出に強い。主に検出用 |
| ハミング符号 | 情報ビットに複数の検査ビットを付け、どの検査が合わないかで誤り位置を特定 | 1 ビットの誤りを訂正できる。ECC メモリなどで利用 |
| チェックサム | データを一定単位で足し合わせた値を付加 | 簡易な誤り検出 |

パリティは 2 ビットが同時に反転すると 1 の個数の偶奇が変わらないため、**2 ビット誤りは検出できない** 点に注意します。

## 例題

**例題1** 記号 A・B・C・D の出現確率が 0.4、0.3、0.2、0.1 のとき、ハフマン符号の 1記号あたりの平均符号長を求めよ。

**解き方**

```
① 最小の C(0.2) と D(0.1) をまとめる → CD(0.3)
② 最小の B(0.3) と CD(0.3) をまとめる → BCD(0.6)
③ A(0.4) と BCD(0.6) をまとめる → 根
符号の例: A=0, B=10, C=110, D=111
```

$$
\text{平均符号長} = 0.4 \times 1 + 0.3 \times 2 + 0.2 \times 3 + 0.1 \times 3 = 1.9 \text{ ビット}
$$

固定長なら 4 種類で 2 ビット必要なので、約 5 % 短くなります（エントロピーは約 1.85 ビット）。

**例題2** 7ビットのデータ `1011001` に偶数パリティを付けるとき、パリティビットは何か。

**解き方**: 1 の個数は 4 個（偶数）なので、パリティビットは **0** です。

**例題3** 4ビットの情報を 7ビットにするハミング符号で、ビット位置 1〜7 のうち位置 1・2・4 を検査ビットとし、次の 3 つの式がすべて 0 になるように作る（⊕ は XOR）。

$$
\begin{aligned}
s_1 &= b_1 \oplus b_3 \oplus b_5 \oplus b_7 \\
s_2 &= b_2 \oplus b_3 \oplus b_6 \oplus b_7 \\
s_4 &= b_4 \oplus b_5 \oplus b_6 \oplus b_7
\end{aligned}
$$

受信データ $b_1$〜$b_7$ が `0110001` のとき、誤りのある位置は。

**解き方**: $s_1 = 0 \oplus 1 \oplus 0 \oplus 1 = 0$、$s_2 = 1 \oplus 1 \oplus 0 \oplus 1 = 1$、$s_4 = 0 \oplus 0 \oplus 0 \oplus 1 = 1$。
$(s_4 s_2 s_1) = (110)_2 = 6$ なので **位置 6** が誤りです。$b_6$ を反転した `0110011` が正しい符号になります。

## 試験対策のポイント

- **ITパスポート**: 可逆圧縮・非可逆圧縮の違いと、ハフマン法・ランレングス法が圧縮の方式であることを用語として押さえます。
- **基本情報技術者**: 情報量の計算、ハフマン符号の平均符号長、パリティビットの値、ハミング符号の誤り位置の特定が定番です。ハミング符号は問題文で検査式が与えられるので、式に代入して XOR を計算すれば解けます。
- **応用情報技術者**: エントロピーの計算や、各誤り検出・訂正方式の能力比較（検出のみか訂正までできるか、何ビットまでか）が問われます。
