コンピュータ内部では、整数も小数も負の数もすべて決まった桁数のビット列で表現されます。
ここでは「数をビット列でどう表すか」と「その表現にどんな制約（範囲・誤差）があるか」を学びます。

## この分野の全体像

| トピック | 学ぶこと | 主な試験 |
| --- | --- | --- |
| 基数変換 | 2進数・8進数・10進数・16進数の相互変換、小数の変換 | IP / FE / AP |
| 補数による負数表現 | 1の補数・2の補数、表現できる範囲、補数を使った減算 | FE / AP |
| 浮動小数点数 | 符号・指数・仮数による表現、IEEE 754、丸め誤差・桁落ち・情報落ち | FE / AP |

## 学ぶ順序

1. **基数変換** … すべての土台です。特に「2進数 ⇔ 16進数（4ビットずつ区切る）」と「10進小数 → 2進小数」は確実に身に付けます。
2. **補数** … 固定桁数の 2進数で負の数を表す方法です。符号付き整数の範囲（例: 8ビットなら −128〜127）はここで理解します。
3. **浮動小数点数** … 非常に大きい数・小さい数・小数を扱うための表現です。有限のビット数で表すために誤差が生じることを理解します。

## 押さえておきたい基本

- n ビットで表せるパターンは **$2^n$ 通り** です（8ビットなら 256 通り）。
- 16進数の 1 桁は 2進数の 4 桁、8進数の 1 桁は 2進数の 3 桁に対応します。
- 10進数の 0.1 のように、2進数では **有限桁で表せない小数** があり、これが誤差の原因になります。

## 試験対策のポイント

- ITパスポートでは、基数変換やビット数と表現できる数の関係が中心です。
- 基本情報・応用情報では、補数表現の範囲や浮動小数点数の誤差の種類（丸め・桁落ち・情報落ち）の判別がよく問われます。
