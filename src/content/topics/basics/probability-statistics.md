**確率** は「ある事象がどのくらいの割合で起こるか」、**統計** は「集めたデータがどのような傾向・ばらつきを持つか」を数値で表す道具です。
待ち行列や信頼性の計算、データ分析、情報量の計算など、IT の多くの分野の前提になります。

## 場合の数

| 考え方 | 式 | 例 |
| --- | --- | --- |
| 和の法則 | A または B（同時に起こらない）→ $a + b$ 通り | 大小2個のさいころで目の和が 2 か 3 → $1 + 2 = 3$ 通り |
| 積の法則 | A かつ B（続けて起こる）→ $a \times b$ 通り | 3種類のシャツと 4種類のズボン → 12 通り |
| 階乗 | $n! = n \times (n - 1) \times \cdots \times 1$（$0! = 1$） | $5! = 120$ |
| 順列（並べ方） | ${}_n\mathrm{P}_r = \dfrac{n!}{(n - r)!}$ | 5人から3人を選んで1列に並べる → ${}_5\mathrm{P}_3 = 60$ |
| 組合せ（選び方） | ${}_n\mathrm{C}_r = \dfrac{n!}{r! \times (n - r)!}$ | 5人から3人を選ぶ → ${}_5\mathrm{C}_3 = 10$ |

順列は **順序を区別する**、組合せは **順序を区別しない** 点が違います。${}_n\mathrm{C}_r = \dfrac{{}_n\mathrm{P}_r}{r!}$ の関係があります。

## 確率の基本定理

全体の起こり方が同様に確からしいとき、事象 A の確率は $P(A) = \dfrac{\text{A が起こる場合の数}}{\text{全体の場合の数}}$ で、$0 \leqq P(A) \leqq 1$ です。

| 定理 | 式 | ポイント |
| --- | --- | --- |
| 余事象 | $P(\text{Aでない}) = 1 - P(A)$ | 「少なくとも1回」は余事象で考えると楽 |
| 加法定理 | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ | 同時に起こらない（排反）なら $P(A) + P(B)$ |
| 乗法定理 | $P(A \cap B) = P(A) \times P(B \mid A)$ | A と B が独立なら $P(A) \times P(B)$ |
| 条件付き確率 | $P(B \mid A) = \dfrac{P(A \cap B)}{P(A)}$ | 「A が起きたとき B が起きる確率」 |

**期待値** は「値 × その値をとる確率」の総和で、平均的に得られる値を表します（例: さいころの目の期待値 $= \dfrac{1 + 2 + \cdots + 6}{6} = 3.5$）。

## 代表値とばらつき

| 指標 | 意味 |
| --- | --- |
| 平均値 | データの総和 ÷ 個数 |
| 中央値（メジアン） | 小さい順に並べたときの真ん中の値（偶数個なら中央2つの平均） |
| 最頻値（モード） | 最も多く現れる値 |
| 分散 | 各データと平均との差（偏差）の 2乗の平均 |
| 標準偏差 | 分散の正の平方根。元のデータと同じ単位でばらつきを表す |

平均値は極端な値（外れ値）の影響を受けやすく、中央値は受けにくいという違いがあります。
**偏差値** は平均を 50、標準偏差を 10 に換算した値で、$\text{偏差値} = 50 + 10 \times \dfrac{\text{得点} - \text{平均}}{\text{標準偏差}}$ です。

## 正規分布

平均を中心に左右対称な釣鐘型の分布です。平均 $\mu$・標準偏差 $\sigma$ の正規分布では、データがおよそ次の割合で含まれます。

| 範囲 | 含まれる割合（約） |
| --- | --- |
| $\mu \pm 1\sigma$ | 68.3 % |
| $\mu \pm 2\sigma$ | 95.4 % |
| $\mu \pm 3\sigma$ | 99.7 % |

## 相関と回帰

- **相関係数** は 2 つの変数の直線的な関係の強さを −1 〜 1 で表します。1 に近いほど正の相関、−1 に近いほど負の相関、0 付近は直線的な相関がないことを示します。
- **回帰直線** $y = ax + b$ は、説明変数 $x$ から目的変数 $y$ を予測する直線で、誤差の 2乗の和が最小になるように求めます（**最小二乗法**）。
- 相関があっても因果関係があるとは限りません。第3の要因によって見かけ上の相関が生じることを **擬似相関** といいます。

## 例題

**例題1** 10本中3本が当たりのくじから、元に戻さずに 2本引くとき、2本とも当たる確率は。

**解き方**: 1本目が当たる確率 $\dfrac{3}{10}$、そのとき 2本目が当たる確率 $\dfrac{2}{9}$。乗法定理より $\dfrac{3}{10} \times \dfrac{2}{9} =$ **1/15**。
（組合せで考えても $\dfrac{{}_3\mathrm{C}_2}{{}_{10}\mathrm{C}_2} = \dfrac{3}{45} = \dfrac{1}{15}$ で一致します）

**例題2** データ 2, 4, 4, 4, 5, 5, 7, 9 の平均・分散・標準偏差を求めよ。

**解き方**

$$
\begin{aligned}
\text{平均} &= \frac{2+4+4+4+5+5+7+9}{8} = \frac{40}{8} = 5 \\[6pt]
\text{偏差の2乗} &= 9,\ 1,\ 1,\ 1,\ 0,\ 0,\ 4,\ 16 \rightarrow \text{合計 } 32 \\[6pt]
\text{分散} &= \frac{32}{8} = 4 \qquad \text{標準偏差} = \sqrt{4} = 2
\end{aligned}
$$

**例題3** 試験の得点が平均 60 点・標準偏差 10 点の正規分布に従うとき、80 点以上の受験者はおよそ何 % か。

**解き方**: 80 点は $\mu + 2\sigma$。$\mu \pm 2\sigma$ に約 95.4 % が入るので、外側は約 4.6 %。左右対称なので上側は約 **2.3 %** です。

## 試験対策のポイント

- **ITパスポート**: 順列・組合せの簡単な計算と、平均値・中央値・最頻値・標準偏差・相関係数などの用語の意味が中心です。
- **基本情報技術者**: 条件付き確率や期待値の計算、分散・標準偏差の計算、正規分布の性質が問われます。「順序を区別するか」で順列と組合せを使い分けることがミスを防ぐ鍵です。
- **応用情報技術者**: 確率分布（二項分布・ポアソン分布など）や回帰分析・仮説検定の考え方まで範囲が広がります。式を暗記するより「何を何で割っているか」を理解しておくと応用が効きます。
