**プログラミング** とは、プログラム言語を使ってアルゴリズムを記述し、コンピュータで実行できる形にすることです。
ここでは、試験でアルゴリズムを表すのに使われる **擬似言語** の読み方、自分自身を呼び出す **再帰** の考え方、
そして書いたプログラムを実行可能にする **言語処理系** と代表的な **プログラム言語** を学びます。

## この分野の全体像

| トピック | 学ぶこと | 主な試験 |
| --- | --- | --- |
| 擬似言語の読み方 | 変数宣言・代入・選択（if）・繰返し（while / do-while / for）・配列・関数と手続、演算子の優先順位、トレース | IP / FE / AP |
| 再帰 | 再帰呼出しと基底条件、階乗・フィボナッチ数の計算、スタックとの関係 | FE / AP |
| プログラム言語と言語処理系 | 機械語・アセンブラ言語・高水準言語、コンパイラ・インタプリタ・リンカ・ローダ、主な言語と HTML・XML・JSON | IP / FE / AP |

## 学ぶ順序

1. **擬似言語の読み方** … まず記述形式に慣れ、変数の値を 1 行ずつ追いかける **トレース** ができるようにします。基本情報技術者試験の科目Bはすべてこの形式で出題されます。
2. **再帰** … 関数呼出しの仕組みを理解したうえで、関数が自分自身を呼び出す処理を追えるようにします。クイックソートやマージソート、木の走査の理解にもつながります。
3. **プログラム言語と言語処理系** … 書いたプログラムがどのように機械語に変換され実行されるかを学び、言語ごとの特徴を整理します。

## アルゴリズムとのつながり

- アルゴリズムの基本構造は **順次・選択・繰返し** の 3 つで、どのプログラム言語でもこの 3 つの組合せで処理を記述します。
- 「アルゴリズムとデータ構造」で学ぶ探索・整列は、科目Bでは擬似言語のプログラムとして出題されます。手順を知っているだけでなく、プログラムの形で読めることが必要です。
- 関数の呼出しと戻りはスタックで管理されるため、データ構造のスタック（LIFO）の理解が再帰の理解を助けます。

## 試験対策のポイント

- **ITパスポート**: 擬似言語で書かれた短いプログラムの読解と、プログラム言語・マークアップ言語（HTML・XML）・JSON の用語が中心です。
- **基本情報技術者**: 科目Bの擬似言語プログラムのトレース・穴埋めが最重要です。科目Aでは言語処理系（コンパイラ・インタプリタ・リンカなど）の役割が問われます。
- **応用情報技術者**: 記述式のアルゴリズム問題でも同じ記述形式の擬似言語が使われ、再帰を含むより長いプログラムの読解が求められます。
