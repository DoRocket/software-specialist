**擬似言語** は、特定のプログラム言語に依存せずにアルゴリズムを表すための、試験用の擬似的なプログラム言語です。
記述形式は IPA の「試験で使用する情報技術に関する用語・プログラム言語など」で定められており、基本情報技術者試験と応用情報技術者試験は共通の形式（ITパスポート試験は別の形式）を使います。
ここでは基本情報・応用情報の形式を中心に説明します。

## 記述形式

| 記述形式 | 意味 |
| --- | --- |
| `○手続名又は関数名` | 手続または関数を宣言する |
| `型名: 変数名` | 変数を宣言する（例: `整数型: x`） |
| `/* 注釈 */`、`// 注釈` | 注釈（コメント） |
| `変数名 ← 式` | 変数に式の値を代入する |
| `手続名又は関数名(引数, …)` | 手続・関数を呼び出し、引数を受け渡す |
| `if (条件式1)` … `elseif (条件式2)` … `else` … `endif` | 選択処理 |
| `while (条件式)` … `endwhile` | 前判定繰返し |
| `do` … `while (条件式)` | 後判定繰返し |
| `for (制御記述)` … `endfor` | 制御記述に基づく繰返し |

実際の問題では、関数の宣言は `○整数型: f(整数型: n)` のように戻り値の型と引数の型を添えて書かれ、戻り値は `return 式` で返します。
配列は `整数型の配列: a` のように宣言されます。

### 選択処理（if）

条件式を **上から順に評価し、最初に真になった条件式の処理だけ** を実行します。それ以降の条件式は評価しません。
どれも真にならなければ `else` の処理を実行します。`elseif` は複数書くことも省略することもでき、`else` は 1 つだけ書くか省略します。

### 繰返し処理

| 構文 | 判定のタイミング | 処理の実行回数 |
| --- | --- | --- |
| `while` | 処理の **前** に条件式を評価（真の間繰り返す） | 0 回以上 |
| `do` 〜 `while` | 処理の **後** に条件式を評価（真の間繰り返す） | 最低 1 回 |
| `for` | 制御記述の内容に基づく | 制御記述による |

実際の問題では、`for (i を 1 から n まで 1 ずつ増やす)` のように制御記述を日本語で書く形がよく使われます。

### 配列

- 要素は `a[i]` のように、`[` と `]` の間に **要素番号** を指定してアクセスします。二次元配列は `b[行番号, 列番号]` です。
- `{` と `}` で配列の内容を表します（例: `{3, 1, 4}`）。二次元配列では内側の `{ }` が 1 行分です。
- 要素番号がいくつから始まるかは問題文に示されます。基本情報技術者試験の科目Bでは **「配列の要素番号は 1 から始まる」** と注記されることが多く、0 から始まる一般的なプログラム言語との違いに注意が必要です。

### 演算子と優先順位

| 優先度 | 種類 | 演算子 |
| --- | --- | --- |
| 高 | 式 | `()`　`.`（メンバ変数・メソッドのアクセス） |
| ↑ | 単項演算子 | `not`　`＋`　`－` |
| | 乗除 | `mod`（剰余）　`×`　`÷` |
| | 加減 | `＋`　`－` |
| | 関係 | `≠ ≦ ≧ ＜ ＝ ＞` |
| ↓ | 論理積 | `and` |
| 低 | 論理和 | `or` |

論理型の定数は `true` と `false` です。`and` は `or` より優先されるので、`x or y and z` は `x or (y and z)` と解釈します。
値が格納されていない状態を **未定義** といいます。

## トレースのコツ

**トレース** とは、変数の値の変化を表に書きながら 1 行ずつ実行を追うことです。

- 繰返しの **1 回ごとに 1 行** の表を作り、条件判定の結果も書く
- 繰返しの最初と最後（境界）で条件式が真か偽かを特に注意して確認する
- `←` は「右辺を計算してから左辺に入れる」。`x ← x ＋ 1` は x を 1 増やす

## 実際の進め方: トレース表を作る

1. **プログラムの目的を先に読む**: 問題文の説明（「最大値の要素番号を返す」など）を読んでからプログラムを見ると、どの変数が何を表すかが分かりやすくなります。
2. **表の列を決める**: 繰返しの制御変数（i など）を左端に、値が変わる変数を右に並べます。`if` や `while` の条件式は「判定」の列にして、真・偽を書きます。
3. **初期値の行を書く**: 繰返しに入る前の各変数の値を1行目に書きます。宣言だけで値を入れていない変数は「未定義」です。
4. **繰返し1回ごとに1行を書く**: その回で条件を判定し、代入があった変数だけ値を書き換えます。変わらない変数も、書き写しておくと読み違いが減ります。
5. **終了の判定を最後の行に書く**: `while` なら条件が偽になった回、`for` なら制御変数が範囲を超えた時点で終わることを書いて確かめます。最後の1回を実行するかどうかが、最も間違えやすいところです。
6. **戻り値・出力を確かめる**: `return` の式を、表の最後の行の値で計算します。
7. **小さな入力で目的と照らし合わせる**: 要素が1つの配列、条件が最初から偽の場合など、境界の入力で結果が目的に合うかを確かめると、穴埋め問題の選択肢を絞り込めます。

## 事例: 最大値の要素番号を求める関数をトレースする

```
○整数型: maxIndex(整数型の配列: a)
  整数型: m ← 1
  整数型: i
  for (i を 2 から aの要素数 まで 1 ずつ増やす)
    if (a[i] ＞ a[m])
      m ← i
    endif
  endfor
  return m
```

`maxIndex({4, 9, 2, 9, 7})` を、要素番号は 1 から始まるものとしてトレースします。

| i | a[i] | a[m]（判定前） | 判定 a[i] ＞ a[m] | m |
| --- | --- | --- | --- | --- |
| （初期値） | | | | 1 |
| 2 | 9 | 4 | 真 | 2 |
| 3 | 2 | 9 | 偽 | 2 |
| 4 | 9 | 9 | 偽 | 2 |
| 5 | 7 | 9 | 偽 | 2 |
| 6 | （要素数 5 を超えたので終了） | | | |

戻り値は **2** です。最大値 9 は要素番号 2 と 4 にありますが、判定が `＞` なので、同じ値では m を更新せず **最初に現れた位置** が返ります。
判定を `≧` に変えると、i ＝ 4 のときも真になって m ＝ 4 となり、**最後に現れた位置** が返ります。このように、`＞` と `≧` の1文字の違いが結果を変えるので、トレース表では判定の列を必ず書きます。

同じ処理を Python で書くと次のようになります。Python の添字は 0 から始まるので、返る値は擬似言語より 1 小さくなります。

```python
def max_index(a):
    m = 0
    for i in range(1, len(a)):   # i = 1, 2, …, len(a) - 1
        if a[i] > a[m]:
            m = i
    return m

max_index([4, 9, 2, 9, 7])   # 1（擬似言語の要素番号では 2）
```

## 擬似言語と一般的なプログラム言語の対応

擬似言語は実際の言語とよく似ているので、知っている言語に置き換えて読むと理解が速くなります。Python との対応を示します。

| 擬似言語 | Python | 注意点 |
| --- | --- | --- |
| `x ← 5` | `x = 5` | 擬似言語の `＝` は代入ではなく比較 |
| `x ＝ y`、`x ≠ y` | `x == y`、`x != y` | |
| `a mod b` | `a % b` | 負の数の剰余は言語によって結果が違うことがある。試験では問題文の定義に従う |
| `and`、`or`、`not` | `and`、`or`、`not` | 優先順位も同じく `not` → `and` → `or` |
| `for (i を 1 から n まで 1 ずつ増やす)` | `for i in range(1, n + 1):` | Python の `range` は終わりの値を含まない |
| `a[1]`（要素番号が 1 から始まる場合） | `a[0]` | 要素番号の始まりの違いで、境界の条件（`＜` か `≦` か）がずれる |
| `aの要素数` | `len(a)` | |
| `endif`、`endwhile`、`endfor` | 字下げ（インデント）で範囲を表す | 擬似言語も字下げで範囲が分かるように書かれている |

### よくある読み間違い

- `if` 〜 `elseif` で、**真になった最初の1つだけ** を実行することを忘れて、後ろの処理も実行してしまう
- `while` の条件を「終わる条件」と読んでしまう（実際は **真の間繰り返す** 条件）
- 代入の順序を入れ替えて読む（`a ← b`、`b ← a` と続けると、2行目では a はすでに b の値なので、入れ替えにはならない）
- 関数の中で宣言した変数と、呼出し元の同じ名前の変数を同じものとみなしてしまう

## 例題

**例題1** 次の関数 `sumOdd({3, 8, 5, 6, 7})` の戻り値は。配列の要素番号は 1 から始まる。

```
○整数型: sumOdd(整数型の配列: a)
  整数型: s ← 0
  整数型: i
  for (i を 1 から aの要素数 まで 1 ずつ増やす)
    if (a[i] mod 2 ＝ 1)
      s ← s ＋ a[i]
    endif
  endfor
  return s
```

**解き方**

| i | a[i] | a[i] mod 2 | s |
| --- | --- | --- | --- |
| 1 | 3 | 1（真） | 3 |
| 2 | 8 | 0（偽） | 3 |
| 3 | 5 | 1（真） | 8 |
| 4 | 6 | 0（偽） | 8 |
| 5 | 7 | 1（真） | 15 |

奇数の要素だけを足しているので、戻り値は **15** です。

**例題2** 次の 2 つの処理を実行した後の x の値をそれぞれ答えよ。

```
// 処理A                    // 処理B
整数型: x ← 30              整数型: x ← 30
while (x ＜ 10)             do
  x ← x × 3                   x ← x × 3
endwhile                    while (x ＜ 10)
```

**解き方**: 処理A は最初の判定で 30 ＜ 10 が偽なので一度も実行せず **30**。処理B は先に 1 回実行して x = 90、その後の判定が偽で終了するので **90** です。
前判定と後判定の違いは、このように「最初から条件が偽のとき」に表れます。

## 試験対策のポイント

- **ITパスポート**: 短い擬似言語のプログラムを読み、出力や変数の値を答える問題が出ます。ITパスポート用の記述形式は別に定められているので、問題文の説明に従って読みます。
- **基本情報技術者**: 科目Bはすべて擬似言語で出題されます。トレース表を素早く書けること、`if`〜`elseif` が最初に真になった 1 つだけを実行すること、要素番号が 1 から始まることによる境界条件（`＜` か `≦` か）に注意します。
- **応用情報技術者**: 同じ記述形式で、より長いプログラムの穴埋めや処理内容の説明が求められます。
