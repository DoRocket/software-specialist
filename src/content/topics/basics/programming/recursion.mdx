**再帰** とは、関数（または手続）の処理の中で自分自身を呼び出すことです（**再帰呼出し**）。
「大きな問題を、同じ形をした小さな問題に分けて解く」アルゴリズムを短く書けるため、クイックソート・マージソート（分割統治法）や木の走査などで使われます。

## 仕組み

### 基底条件と再帰ステップ

再帰関数は必ず次の 2 つの部分から成ります。

| 部分 | 役割 | 階乗 n! の場合 |
| --- | --- | --- |
| 基底条件（終了条件） | それ以上自分を呼ばずに値を返す | $n \leqq 1$ なら 1 を返す |
| 再帰ステップ | 問題を小さくして自分自身を呼び出す | $n \times (n - 1)!$ を返す |

基底条件がない、または引数が基底条件に近づかないと、呼出しが無限に続いてしまいます。

```
○整数型: fact(整数型: n)
  if (n ≦ 1)
    return 1                  // 基底条件
  else
    return n × fact(n － 1)   // 再帰ステップ
  endif
```

### スタックとの関係

関数を呼び出すと、**戻り先** や **引数・局所変数** などの情報がスタックに積まれ、関数から戻るときに取り出されます。
再帰呼出しでは、呼出しのたびに新しい引数・局所変数の組がスタックに積まれるため、同じ関数でも呼出しごとに別々の値を保持できます。
最後に呼ばれたものから先に戻る（後入れ先出し、**LIFO**）ので、再帰の実現には **スタック** が適しています。

- 呼出しが深くなるほどスタックの使用量が増え、上限を超えるとスタックオーバフローになります
- 再帰で書いた処理は、スタックを自分で用意すれば繰返し（ループ）でも書けます
- 自分自身を呼び出して正しく動作するプログラムの性質を **再帰的（リカーシブ）** といいます。呼出しごとに局所変数を別々に持つ必要があるため、複数から同時に呼ばれても正しく動く **再入可能（リエントラント）** の考え方と関係が深い性質です

### fact(4) の呼出しと戻り

```
fact(4) → 4 × fact(3)           ← 呼出し（スタックに積む）
            fact(3) → 3 × fact(2)
                       fact(2) → 2 × fact(1)
                                  fact(1) → 1   （基底条件）
                       fact(2) = 2 × 1 = 2      ← 戻り（スタックから取り出す）
            fact(3) = 3 × 2 = 6
fact(4) = 4 × 6 = 24
```

呼出しの途中では掛け算は行われず、基底条件に達してから **戻りながら** 計算が進む点がポイントです。

## 代表的な再帰

| 例 | 定義 |
| --- | --- |
| 階乗 | $n! = n \times (n - 1)!$、$1! = 1$ |
| フィボナッチ数 | $\mathrm{fib}(n) = \mathrm{fib}(n - 1) + \mathrm{fib}(n - 2)$、$\mathrm{fib}(1) = \mathrm{fib}(2) = 1$ |
| 最大公約数（ユークリッドの互除法） | $\gcd(a, b) = \gcd(b,\ a \bmod b)$、$b = 0$ なら $a$ |
| ハノイの塔 | n 枚の移動回数は $2^n - 1$ 回 |

フィボナッチ数を上の定義どおり再帰で求めると、同じ値を何度も計算し直すため、呼出し回数が n に対して指数関数的に増えます。

## 例題

**例題1** 次の関数で fib(5) を求めるとき、戻り値と、fib が呼び出される回数（最初の呼出しを含む）は。

```
○整数型: fib(整数型: n)
  if (n ≦ 2)
    return 1
  else
    return fib(n － 1) ＋ fib(n － 2)
  endif
```

**解き方**: 呼出しの木を書きます。

```
fib(5)
├─ fib(4)
│   ├─ fib(3)
│   │   ├─ fib(2)
│   │   └─ fib(1)
│   └─ fib(2)
└─ fib(3)
    ├─ fib(2)
    └─ fib(1)
```

戻り値は $\mathrm{fib}(5) = \mathrm{fib}(4) + \mathrm{fib}(3) = 3 + 2 =$ **5**。木の節の数を数えると呼出し回数は **9 回** です（fib(3) を 2 回計算している無駄が分かります）。

**例題2** gcd(48, 18) を、gcd(a, b) = 「b ＝ 0 なら a、そうでなければ gcd(b, a mod b)」で求めよ。

**解き方**

```
gcd(48, 18) → 48 mod 18 = 12 → gcd(18, 12)
gcd(18, 12) → 18 mod 12 = 6  → gcd(12, 6)
gcd(12, 6)  → 12 mod 6  = 0  → gcd(6, 0) → 6
```

答えは **6** です。
