コンピュータは、演算と制御を行う **CPU**、プログラムやデータを保持する **記憶装置**、それらを管理してアプリケーションに使いやすい環境を提供する **OS** などから構成されます。
この分野では各構成要素の仕組みに加えて、システム全体を **性能（どれだけ速いか）** と **信頼性（どれだけ止まらないか）** の観点から評価する方法を学びます。

## この分野の全体像

| トピック | 学ぶこと | 主な試験 |
| --- | --- | --- |
| CPU の構成と性能 | 制御装置・演算装置・レジスタ、命令実行サイクル、クロック・CPI・MIPS、パイプライン | IP / FE / AP |
| 記憶階層とキャッシュメモリ | レジスタ〜補助記憶の階層、キャッシュのヒット率と実効アクセス時間、書込み方式 | IP / FE / AP |
| OS とプロセス管理 | OS の役割、タスクの状態遷移、スケジューリング、仮想記憶・ページング | IP / FE / AP |
| システムの信頼性 | MTBF・MTTR・稼働率、直列・並列システム、RAID、フォールトトレランス | IP / FE / AP |

## 学ぶ順序

1. **CPU** … 命令がどのように実行されるかを理解し、性能指標（クロック周波数・CPI・MIPS）の計算に慣れます。
2. **記憶階層とキャッシュ** … CPU と主記憶の速度差を埋める仕組みです。実効アクセス時間の計算は CPU の性能評価と同じ考え方でつながります。
3. **OS** … 限られた CPU とメモリを複数のプログラムで効率よく共有する仕組みです。仮想記憶は記憶階層の知識を前提にします。
4. **信頼性** … 個々の装置が故障することを前提に、システム全体としての稼働率を高める考え方を学びます。

## 他分野とのつながり

- CPU の演算回路や数値の扱いは、基礎理論の「数値表現」「論理演算と論理回路」が土台になっています。
- 稼働率や性能の計算は、システム構成の設計やサービスマネジメントの分野でも繰り返し使われます。

## 試験対策のポイント

- **ITパスポート**: 各装置の役割、クロック周波数やキャッシュの意味、稼働率の基本的な計算が中心です。
- **基本情報技術者**: MIPS・実効アクセス時間・稼働率などの計算問題が科目Aで頻出です。公式を覚えるだけでなく、意味から導けるようにしておきます。
- **応用情報技術者**: 複数の要素を組み合わせた計算（キャッシュを含む CPU 性能、複雑な直並列構成の稼働率など）や、方式の比較・選択が問われます。
