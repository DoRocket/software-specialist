経済産業省は、システム監査に関する2つの基準を公表しています。**システム監査基準** は「監査人がどう監査を行うべきか」、**システム管理基準** は「組織が IT をどう管理すべきか」を示すものです。
2つの役割の違いと、システム監査基準が監査人に求める倫理・姿勢を押さえると、「監査人の行動として適切なものはどれか」という問題が解けるようになります。

## 2つの基準の役割の違い

| | システム監査基準 | システム管理基準 |
| --- | --- | --- |
| 誰のためのものか | システム監査人 | 監査を受ける組織体（経営者・IT 部門など） |
| 何を示すか | 監査人の倫理、監査の体制整備・計画・実施・報告などの **行為規範** | IT ガバナンスと IT マネジメントを実践するための **実践規範** |
| 監査での使われ方 | 監査業務の品質を確保し、有効かつ効率的に監査を行うためのよりどころ | 監査対象が適切かを判断する **判断尺度**（監査上の判断尺度）の参照基準 |

例えると、システム監査基準は「審判が守るべきルール」、システム管理基準は「選手のプレーを評価するときの採点基準」に当たります。

システム管理基準は、IT ガバナンスに加えて、情報システムの企画・開発（アジャイル開発を含む）・運用・保守、外部サービスの利用など、IT マネジメントの各領域で組織が実施すべき事項を示しています。
監査人は、判断尺度を決めるときに管理基準を **客観的な参照基準** として用いることができます。ただし、組織の状況に合わせて項目を選んだり、他の基準（情報セキュリティ管理基準など）を使ったりしてもかまいません。

## 監査人に求められる倫理と姿勢

システム監査基準は、監査人に高い倫理観と次のような姿勢を求めています。

| 要求事項 | 内容 |
| --- | --- |
| 誠実性 | 監査人として誠実に業務を行い、倫理に反する行為をしない |
| 独立性 | 監査対象から独立した立場で監査を行う（下記） |
| 客観性 | 利害関係や先入観にとらわれず、証拠に基づいて公正に判断する |
| 専門的能力の保持と向上 | 監査に必要な知識・技能を持ち、継続的に高める |
| 正当な注意 | 専門職として求められる注意を払って監査を行う |
| 秘密の保持 | 監査で知り得た秘密を、正当な理由なく他に漏らしたり自らの利益に使ったりしない |

### 独立性

独立性は、監査の結論を信頼してもらうための前提です。試験では次の2つに分けて問われます。

- **外観上の独立性** … 監査対象と組織上・身分上の利害関係がないこと。例えば、監査対象部門に所属している人や、対象システムを開発した人は、そのシステムの監査人に適していません。
- **精神上の独立性** … 監査対象に対して公正かつ客観的な態度を保つこと。

内部監査部門は、監査対象の部門から独立させるため、経営者（社長など）の直属に置くのが一般的です。

### 専門的能力と他の専門家の利用

監査に必要な専門知識が足りない領域では、外部の専門家の支援を受けることがあります。その場合も、専門家の作業結果を監査の結論に用いるかどうかの判断と責任は監査人にあります。

## 体制の整備

監査の品質を一定に保つため、組織として監査の体制を整えることも求められます。

- **権限と責任の明確化** … 内部監査なら **内部監査規程**、外部に委託するなら **システム監査委託契約書** で、監査の目的・対象範囲・権限・責任を定めます。
- **ニーズの把握と品質の確保** … 監査の依頼者のニーズを把握し、監査の品質を評価・改善する仕組みを持ちます。

## 保証型監査と助言型監査

システム監査は、監査の目的に応じて次の2つに分けられます。

| | 保証を目的としたシステム監査 | 助言を目的としたシステム監査 |
| --- | --- | --- |
| 目的 | 監査対象のコントロールが判断尺度に照らして適切に整備・運用されていることを、一定の水準で **保証** する | コントロールの改善が必要な点を指摘し、**改善提案** を行う |
| 監査報告書の中心 | 保証の結論（意見） | 指摘事項と改善提案 |
| 主な使われ方 | 利害関係者や経営者に対して、管理の状況が適切であることを示す | 組織が自ら IT の管理を改善する |

2つを組み合わせて、保証を行ったうえで改善提案を添えることもあります。

## 監査人がしてよいこと・いけないこと

監査人の役割は **検証・評価して、保証や助言を行うこと** です。監査対象の業務そのものを行うと、自分の仕事を自分で評価することになり、独立性が損なわれます。

| してよい（監査人の役割） | してはいけない（独立性・倫理に反する） |
| --- | --- |
| 指摘事項を示し、改善提案を行う | 監査人自身がプログラムを修正するなど、改善を実施する |
| 改善の実施状況をフォローアップで確認する | 監査対象システムの運用業務を担当する |
| 監査報告の前に、指摘事項の事実関係を監査対象部門と確認する | 自分が開発・運用に関わったシステムを監査する |
| 監査の依頼者に監査報告書を提出する | 監査で知り得た情報を、正当な理由なく外部に漏らす |
| 判断尺度を、組織の状況に合わせて選ぶ | 証拠を集めずに推測で結論を出す |

## 例題

**問1** システム監査人の行動のうち、独立性の観点から問題があるものはどれか。

- ア 監査で発見したアクセス権限の設定誤りについて、監査報告書で改善提案を行った。
- イ 監査対象のシステムの運用担当者が不足していたので、監査期間中に監査人がバッチ処理の運用を代行した。
- ウ 監査報告書の作成前に、指摘事項の内容に事実誤認がないか監査対象部門と確認した。
- エ 改善計画に基づく対応の状況を、フォローアップで確認した。

**解き方** イは監査人が監査対象の業務（運用）に関与しており、自らの業務を評価することになるため独立性を損ないます。正解は **イ** です。ア・エは監査人の本来の役割、ウは報告書の正確性を高めるための適切な手続です。

**問2** システム監査で、システム管理基準はどのように用いられるか。

- ア 監査人が守るべき行為規範として用いる。
- イ 監査対象が適切かどうかを判断する尺度の参照基準として用いる。
- ウ 監査報告書の様式として用いる。

**解き方** 監査人の行為規範はシステム監査基準です。システム管理基準は判断尺度の参照基準なので、正解は **イ** です。

## 試験対策のポイント

- **ip**: システム監査人が独立かつ客観的な立場であること、システム監査基準が経済産業省によるものであることを押さえます。
- **fe**: システム監査基準（監査人の行為規範）とシステム管理基準（判断尺度）の違い、正当な注意と秘密の保持、保証型と助言型の違いが問われます。
- **ap**: 具体的な場面で監査人の行動が適切かを判断する問題が中心です。「監査人が業務や改善の実施に関与していないか」「証拠に基づいているか」「独立性を損なう関係がないか」の3点で確かめます。
