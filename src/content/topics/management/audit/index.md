システム監査は、独立かつ専門的な立場のシステム監査人が、情報システムに関わるリスクに対するコントロール（管理・統制）が適切に整備・運用されているかを点検・評価し、結果を報告する活動です。
日本では経済産業省が「システム監査基準」「システム管理基準」を公表しています。

このページでは全体像をまとめます。監査の進め方と監査技法、2つの基準と監査人の倫理、内部統制と IT ガバナンス、さまざまな監査と関連法規は、下の子トピックで詳しく扱います。

## 監査の目的と種類

システム監査の目的は、組織の **ITガバナンスの実現に寄与** し、情報システムが経営に役立つよう有効かつ効率的に活用されているか、リスクが適切に管理されているかを確かめることです。

| 種類 | 内容 |
| --- | --- |
| 内部監査 | 組織内の監査部門などが行う |
| 外部監査 | 組織外部の監査人が行う |
| 保証型監査 | 一定の水準でコントロールが機能していることを保証する |
| 助言型監査 | 問題点を指摘し、改善のための助言を行う |

## システム監査人の独立性

監査結果を信頼してもらうため、監査人には独立性が求められます。

- **外観上の独立性** … 監査対象の部門や業務から組織上・身分上独立していること。例えば、対象システムの開発担当者が自らそのシステムを監査するのは不適切です。
- **精神上の独立性** … 公正かつ客観的に判断する姿勢を保つこと。

監査人は監査対象の業務に直接関与せず、改善の **実施は監査対象部門が行い**、監査人はその状況を確認（フォローアップ）します。

## 監査の手順

| 段階 | 内容 |
| --- | --- |
| 監査計画 | 監査の目的・対象・範囲・スケジュールを決める |
| 予備調査 | 資料の閲覧やヒアリングで、対象の概要と問題点の見当をつける |
| 本調査 | 監査手続（閲覧、インタビュー、観察、テストなど）を実施し、監査証拠を入手する |
| 評価・結論 | 入手した監査証拠に基づいて、コントロールの妥当性を評価する |
| 報告 | 監査報告書を作成し、監査の依頼者（経営者など）に提出する。指摘事項と改善提案を含む |
| フォローアップ | 改善提案への対応状況を確認する |

監査人が実施した手続や入手した証拠を記録した文書を **監査調書** といい、監査意見の根拠になります。

## 監査証跡

**監査証跡（オーディットトレール）** は、処理の流れを後から追跡できるようにするための記録です。入力から出力までの各段階のログ、操作ログ、アクセスログなどが該当します。
監査証跡によって、誰がいつ何をしたかを確認でき、データの正確性や不正の有無を検証できます。そのため、ログの改ざん防止や一定期間の保存も重要なコントロールです。

## 内部統制

内部統制は、組織の業務を適正に進めるために経営者が整備・運用する仕組みです。金融商品取引法に基づく財務報告に係る内部統制の基準では、次の4つの目的と6つの基本的要素が示されています。

| 4つの目的 | 6つの基本的要素 |
| --- | --- |
| 業務の有効性及び効率性 | 統制環境 |
| 報告の信頼性 | リスクの評価と対応 |
| 事業活動に関わる法令等の遵守 | 統制活動 |
| 資産の保全 | 情報と伝達 |
| | モニタリング（監視活動） |
| | IT（情報技術）への対応 |

内部統制の代表的な手段に **職務分掌**（業務の担当を分け、1人に権限を集中させない）があります。例えば、発注担当と検収担当を分けることで、不正や誤りを相互にけん制できます。

## 例題

**問** システム監査人の行動として最も適切なものはどれか。

- ア 監査で発見した問題点を、監査人自らプログラムを修正して解決した。
- イ 監査報告書に改善提案を記載し、その後の改善状況をフォローアップした。
- ウ 自分が開発責任者だったシステムを監査した。

**解き方** アは監査人が改善を実施しており、ウは外観上の独立性を損なっています。正解は **イ** です。

## 試験対策のポイント

- **ip**: 監査人の独立性、監査報告書の提出先（監査の依頼者）、内部統制・職務分掌の意味が頻出です。
- **fe**: 監査手続の流れ、監査証跡の役割、具体的なコントロールの例が適切かどうかを判断する問題が出題されます。
- **ap**: 監査の観点から特定のコントロール（アクセス管理、変更管理、バックアップなど）を評価する問題が中心です。どの監査証拠で何を確かめるかを考える練習をします。
