プロジェクトとは、独自の成果物を作るために行う **有期性**（開始と終了がある）の活動です。
プロジェクトマネジメントは、スコープ（範囲）・スケジュール・コスト・品質などを計画し、監視・コントロールしながらプロジェクトを完了に導く活動です。

## PMBOKの知識エリア

PMBOK（Project Management Body of Knowledge）は、米国の PMI がまとめたプロジェクトマネジメントの知識体系です。
試験では第6版までの **10の知識エリア** が問われることが多いので、各エリアの目的を押さえます（第7版では、原理・原則とパフォーマンス領域を中心とする構成に改められています）。

| 知識エリア | 主な内容 |
| --- | --- |
| 統合マネジメント | プロジェクト憲章の作成、全体の調整、変更管理 |
| スコープマネジメント | 作業範囲の定義、WBS の作成 |
| スケジュールマネジメント | アクティビティの順序付け・所要期間の見積り、スケジュール作成 |
| コストマネジメント | コストの見積り、予算設定、コストのコントロール |
| 品質マネジメント | 品質の計画、品質保証、品質のコントロール |
| 資源マネジメント | 要員などの資源の計画・獲得、チームの育成 |
| コミュニケーションマネジメント | 情報の作成・配布・管理 |
| リスクマネジメント | リスクの特定・分析・対応計画 |
| 調達マネジメント | 外部からの製品・サービスの購入、契約管理 |
| ステークホルダーマネジメント | 利害関係者の特定と関与の管理 |

## WBS

**WBS（Work Breakdown Structure）** は、プロジェクトの成果物や作業を階層的に分解した図です。最下位の要素を **ワークパッケージ** と呼び、ここを単位に工数・コスト・担当者を見積もります。
WBS に含まれない作業はプロジェクトのスコープ外、という判断の基準にもなります。

## アローダイアグラムとクリティカルパス

**アローダイアグラム（PERT図）** は、作業（アクティビティ）を矢印、作業の区切り（結合点）を丸で表し、作業の順序関係を示す図です。
作業の順序関係だけを表し所要時間 0 の矢印を **ダミー作業**（点線）と呼びます。

開始から終了までの経路のうち、所要日数が最も長い経路を **クリティカルパス** といいます。クリティカルパス上の作業が遅れると、プロジェクト全体が遅れます。

### 例題（クリティカルパス）

次の作業からなるプロジェクトの最短所要日数とクリティカルパスを求めよ。

| 作業 | 結合点 | 所要日数 |
| --- | --- | --- |
| A | 1 → 2 | 3 |
| B | 1 → 3 | 4 |
| C | 2 → 4 | 5 |
| D | 3 → 4 | 3 |
| E | 4 → 5 | 2 |

図の「次へ」で、結合点ごとの計算とクリティカルパスを順に確かめられます。

**解き方**

1. **最早結合点時刻**（前から、合流点では最大値）: ①$= 0$、②$= 0 + 3 = 3$、③$= 0 + 4 = 4$、④$= \max(3 + 5,\ 4 + 3) = 8$、⑤$= 8 + 2 =$ **10**
2. **最遅結合点時刻**（後ろから、分岐点では最小値）: ⑤$= 10$、④$= 10 - 2 = 8$、③$= 8 - 3 = 5$、②$= 8 - 5 = 3$、①$= \min(3 - 3,\ 5 - 4) = 0$
3. 最早と最遅が一致する結合点（①②④⑤）を結ぶ経路 **A→C→E** がクリティカルパスで、最短所要日数は **10日**。
4. 経路 B→D は 7日で、④までの 8日に対して **1日の余裕（フロート）** があります。

## EVM（アーンドバリューマネジメント）

進捗とコストを金額という共通の尺度で管理する手法です。

| 指標 | 意味 |
| --- | --- |
| PV（計画価値） | その時点までに完了予定だった作業の予算 |
| EV（出来高） | その時点までに実際に完了した作業の予算上の価値 |
| AC（実コスト） | その時点までに実際にかかったコスト |
| $\text{SV} = \text{EV} - \text{PV}$ | スケジュール差異（負ならスケジュール遅れ） |
| $\text{CV} = \text{EV} - \text{AC}$ | コスト差異（負ならコスト超過） |
| $\text{SPI} = \dfrac{\text{EV}}{\text{PV}}$ | スケジュール効率指数（1未満なら遅れ） |
| $\text{CPI} = \dfrac{\text{EV}}{\text{AC}}$ | コスト効率指数（1未満なら超過） |

### 例題（EVM）

ある時点で PV = 100万円、EV = 80万円、AC = 90万円だった。状況を評価せよ。

**解き方** $\text{SV} = 80 - 100 =$ **−20万円**（遅れ）、$\text{CV} = 80 - 90 =$ **−10万円**（超過）。$\text{SPI} = 0.8$、$\text{CPI} \fallingdotseq 0.89$ で、**スケジュールが遅れ、コストも超過** しています。
総予算（BAC）が 500万円で今後も同じ効率が続くと仮定すると、完成時総コスト見積り（EAC）は $\text{BAC} \div \text{CPI} = 500 \div \dfrac{80}{90} =$ **562.5万円** です。

## 試験対策のポイント

- **ip**: 知識エリアの名前と内容の対応、WBS・クリティカルパスの意味、簡単なクリティカルパスの日数計算が出題されます。
- **fe**: 最早・最遅結合点時刻の計算、作業短縮時の全体日数の変化、EVM の指標計算を確実に解けるようにします。
- **ap**: EVM の値から状況を判断して対策を選ぶ問題、ファストトラッキング（並行実施）とクラッシング（資源追加）によるスケジュール短縮の違い、リスク対応戦略（回避・転嫁・軽減・受容）なども問われます。
