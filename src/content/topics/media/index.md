どれほど高性能なシステムでも、利用者にとって使いにくければ価値を発揮できません。また、現在のシステムは文字だけでなく、音声・画像・動画といった多様な情報を扱います。
この分野では、人とシステムの接点である **ヒューマンインタフェース** の設計の考え方と、さまざまな情報をデジタルデータとして扱う **マルチメディア** の技術を学びます。

## この分野の全体像

| トピック | 学ぶこと | 主な試験 |
| --- | --- | --- |
| ヒューマンインタフェース | GUI の部品と使い分け、UX とユーザビリティ、アクセシビリティとユニバーサルデザイン、Web デザインの考え方 | IP / FE / AP |
| マルチメディア | 画素・解像度・色深度、RGB と CMYK、静止画・音声・動画の形式と圧縮、PCM によるデジタル化、データ量の計算、VR / AR | IP / FE / AP |

## 学ぶ順序

1. **ヒューマンインタフェース** … 画面の部品や操作方法の特徴を押さえ、「誰にとって、どう使いやすいか」を考える視点を身に付けます。
2. **マルチメディア** … 音や画像をどのようにビット列で表すかを理解し、データ量の計算と圧縮方式の選び方に慣れます。

## 他分野とのつながり

- 音声や画像のデジタル化は、基礎理論の「数値表現」（ビット数と表現できる値の数）が土台です。
- 画像・動画のデータ量の計算は、ネットワークの「伝送時間の計算」と組み合わせて出題されます。
- ディスプレイやスキャナなどの入出力装置、タッチパネルなどの入力方法はコンピュータシステムの分野とも関係します。

## 試験対策のポイント

- **ITパスポート**: GUI 部品の使い分け、ユニバーサルデザイン・アクセシビリティの意味、画像・音声・動画のファイル形式、可逆 / 非可逆圧縮、VR / AR などの用語が中心です。
- **基本情報技術者**: 画像・音声のデータ量の計算、圧縮方式の特徴、UX デザインやユーザビリティ評価の手法、入力チェックの種類が問われます。
- **応用情報技術者**: ユーザビリティ評価手法の使い分けやユニバーサルデザインの原則の適用、用途に応じた圧縮方式・形式の選択など、設計・比較の観点が加わります。
