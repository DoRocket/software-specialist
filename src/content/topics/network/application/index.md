アプリケーション層は、Webの閲覧やメールの送受信など、**利用者やアプリケーションが直接使うサービス** のためのプロトコルが属する層です。
これらのプロトコルは、下位のトランスポート層（TCP/UDP）を使ってデータを運びます。

## この分野で学ぶこと

- **DNS** … ドメイン名と IPアドレスを対応付ける名前解決の仕組み
- **DHCP** … IPアドレスなどのネットワーク設定を自動で配布する仕組み
- **主なアプリケーションプロトコル** … HTTP/HTTPS、メール（SMTP/POP3/IMAP）、FTP、SSH、NTP など

DNS と DHCP は、利用者が意識しないうちに通信の前段で必ず動いている「インフラ」のプロトコルです。
トラブル時に「名前解決できているか」「IPアドレスを取得できているか」を確認する場面が多いため、仕組みを理解しておきましょう。
