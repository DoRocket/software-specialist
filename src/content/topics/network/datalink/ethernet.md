**Ethernet（イーサネット）** は、有線LANで最も広く使われているデータリンク層・物理層の規格です（IEEE 802.3）。
機器の識別には **MACアドレス** を使います。

## MACアドレス

ネットワークインタフェース（NIC）ごとに割り当てられる **48ビット** の識別子です。

```
00-1A-2B-3C-4D-5E   （8ビットずつ16進数2桁 × 6組で表記。区切りは - や : ）
└──┬───┘ └──┬───┘
  OUI     製造者が割り当てる番号
（上位24ビット: 製造者番号）
```

| 項目 | 内容 |
| --- | --- |
| 長さ | 48ビット（6バイト） |
| 上位24ビット | **OUI**（ベンダ識別子）。IEEE が製造者ごとに割り当てる |
| 下位24ビット | 製造者が製品ごとに一意になるよう割り当てる |
| ブロードキャストアドレス | `FF-FF-FF-FF-FF-FF`（同一ネットワーク内の全機器宛て） |

IPアドレスが「ネットワーク上の論理的な住所」で設定により変わるのに対し、MACアドレスは機器に割り当てられた「物理アドレス」と呼ばれます
（ただし、ソフトウェアで変更したり、スマートフォンなどがプライバシー保護のためランダムなアドレスを使ったりすることもあります）。

## Ethernet フレームの構造（Ethernet II）

| フィールド | サイズ | 内容 |
| --- | --- | --- |
| プリアンブル（SFD含む） | 8バイト | 受信側の同期用の信号パターン |
| 宛先MACアドレス | 6バイト | |
| 送信元MACアドレス | 6バイト | |
| タイプ | 2バイト | 上位プロトコルの種類（IPv4 = 0x0800、ARP = 0x0806、IPv6 = 0x86DD） |
| データ | 46〜1,500バイト | IPパケットなど。最大 1,500 バイトを **MTU** という |
| FCS | 4バイト | CRC による誤り検出用の値 |

受信側は FCS を検査し、誤りがあるフレームは **破棄** します（データリンク層では再送しません。再送は TCP などの上位層の役割です）。

## アクセス制御方式 CSMA/CD

複数の機器が1本の伝送路を共有する（半二重の）Ethernet で使われた方式です。

1. **CS（Carrier Sense）**: 送信前に伝送路が空いているか確認する
2. **MA（Multiple Access）**: 空いていれば送信する（複数の機器が同じ伝送路を使う）
3. **CD（Collision Detection）**: 送信中に衝突（コリジョン）を検知したら送信を中止し、**ランダムな時間** 待って再送する

現在主流のスイッチを使った **全二重通信** では送信と受信が別の線で行われ衝突が起きないため、CSMA/CD は実質的に使われていません。
無線LANでは衝突を検知できないため、衝突を「回避」する CSMA/CA が使われます（[無線LAN](../wireless-lan/) 参照）。

## 主な規格

| 規格 | 通信速度 | 主な伝送媒体 |
| --- | --- | --- |
| 10BASE-T | 10Mビット/秒 | ツイストペアケーブル |
| 100BASE-TX | 100Mビット/秒 | ツイストペアケーブル（カテゴリ5以上） |
| 1000BASE-T | 1Gビット/秒 | ツイストペアケーブル（カテゴリ5e以上） |
| 10GBASE-T | 10Gビット/秒 | ツイストペアケーブル（カテゴリ6A以上） |

名称は「速度 + BASE（ベースバンド方式） + 媒体の種類」を表しています。T はツイストペアケーブル、
1000BASE-SX / LX などは光ファイバを使う規格です。

## 試験対策のポイント

- **ITパスポート**: 「MACアドレスは機器（NIC）固有の番号」「IPアドレスとの違い」を説明できること。
- **基本情報**: MACアドレスが 48 ビットであること、CSMA/CD の動作（衝突検知→ランダム時間後に再送）、
  L2スイッチが MACアドレスで転送先を決めることを押さえる。
- **応用情報**: MTU とフラグメント、VLAN タグ（IEEE 802.1Q）なども含め、フレームのサイズや中継の仕組みが問われる。
