インターネット層（OSI参照モデルのネットワーク層）は、**異なるネットワークをまたいで、最終的な宛先までパケットを届ける** 役割を持ちます。
中心となるプロトコルが **IP（Internet Protocol）** で、宛先の識別に **IPアドレス** を使います。

IP は「宛先に向けて最善を尽くして届ける（ベストエフォート）」だけで、届いたかどうかの確認や再送は行いません。
信頼性の確保は上位の [トランスポート層](../transport/)（TCP）が担います。

## この分野で学ぶこと

1. **IPアドレス** … アドレスの構造（ネットワーク部とホスト部）、クラス、サブネット、プライベートアドレス、IPv6
2. **ルーティング** … ルータが宛先までの経路を選ぶ仕組みとルーティングプロトコル
3. **ARP と ICMP** … IPの通信を支える補助的なプロトコル

まずは IPアドレスの「ネットワーク部／ホスト部」という考え方を確実に理解することが、サブネット計算やルーティングを学ぶ土台になります。
