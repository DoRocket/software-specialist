**IPアドレス** は、IP ネットワーク上で通信相手を識別するための番号です。
現在広く使われている **IPv4** では **32ビット**、後継の **IPv6** では **128ビット** の長さです。

## IPv4アドレスの表記

32ビットを 8ビットずつ 4つに区切り、それぞれを 10進数で表してピリオドでつなぎます（ドット付き10進表記）。

```
2進数:   11000000 10101000 00000001 00001010
10進数:  192     .168     .1       .10
```

各区切り（オクテット）は 8ビットなので、取りうる値は 0〜255 です。

## ネットワーク部とホスト部

IPアドレスは、前半の **ネットワーク部**（どのネットワークか）と、後半の **ホスト部**（そのネットワーク内のどの機器か）に分かれます。
郵便の住所でいう「町名」と「番地」のような関係です。

```
192.168.1.10 /24
└─ネットワーク部(24ビット)─┘└ホスト部(8ビット)┘
   192.168.1                     .10
```

どこまでがネットワーク部かは、かつては **アドレスクラス** で決まっていましたが、
現在は **サブネットマスク**（または CIDR 表記の「/24」のようなプレフィックス長）で柔軟に指定します。

## 特別なアドレス

| アドレス | 意味 |
| --- | --- |
| ホスト部がすべて 0 | **ネットワークアドレス**（ネットワーク自体を表す。機器には割り当てない） |
| ホスト部がすべて 1 | **ブロードキャストアドレス**（そのネットワーク内の全機器宛て。機器には割り当てない） |
| 127.0.0.1（127.0.0.0/8） | **ループバックアドレス**（自分自身を表す） |
| 10.0.0.0/8 など | **プライベートアドレス**（組織内で自由に使える） |

このため、ホスト部が $n$ ビットのネットワークで機器に割り当てられるアドレス数は **$2^n - 2$** 個になります。

## この分野で学ぶこと

1. **アドレスクラス** … クラスA〜Eによる旧来の区分（考え方の基礎として出題される）
2. **サブネットマスクと CIDR** … ネットワークを柔軟に分割・集約する方法と計算
3. **プライベートアドレスと NAT** … 組織内アドレスとインターネットの接続
4. **IPv6** … アドレス枯渇への対策としての次世代アドレス

## 試験対策のポイント

- **ITパスポート**: IPアドレスの役割（機器の識別）、IPv4 が 32 ビット・IPv6 が 128 ビットであること、グローバル/プライベートの違い。
- **基本情報・応用情報**: 2進数との変換、ネットワークアドレス・ブロードキャストアドレスの算出、割当て可能なホスト数（$2^n - 2$）。
