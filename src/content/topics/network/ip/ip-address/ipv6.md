**IPv6** は、IPv4 アドレスの枯渇に対応するために作られた次世代のインターネットプロトコルです。
アドレス長は **128ビット** で、約 $3.4 \times 10^{38}$ 個という事実上使い切れない数のアドレスを持ちます。

## 表記方法

128ビットを **16ビットずつ 8 つ** に区切り、それぞれを **16進数4桁** で表してコロン（:）でつなぎます。

```
2001:0db8:0000:0000:0000:ff00:0042:8329
```

### 省略ルール

1. 各ブロックの **先頭の 0 は省略** できる
   `0db8` → `db8`、`0042` → `42`、`0000` → `0`
2. **0 のブロックが連続する部分は `::` に置き換えられる**。ただし **1つのアドレスで1回だけ**

```
2001:0db8:0000:0000:0000:ff00:0042:8329
→ 2001:db8:0:0:0:ff00:42:8329     (ルール1)
→ 2001:db8::ff00:42:8329          (ルール2)
```

`::` を2回使うと、それぞれ何ブロック分の 0 なのか復元できなくなるため禁止されています。

## 主なアドレスの種類

| 種類 | プレフィックス | 説明 |
| --- | --- | --- |
| グローバルユニキャストアドレス | 2000::/3 | インターネット上で一意（IPv4のグローバルアドレスに相当） |
| リンクローカルアドレス | fe80::/10 | 同一リンク内でのみ有効。インタフェースごとに自動設定される |
| ユニークローカルアドレス | fc00::/7 | 組織内で使う（IPv4のプライベートアドレスに相当） |
| ループバックアドレス | ::1 | 自分自身 |
| マルチキャストアドレス | ff00::/8 | 複数の宛先グループ向け |

IPv6 には **ブロードキャストアドレスがありません**。同様の用途にはマルチキャストを使います。

## IPv4 との主な違い

| 項目 | IPv4 | IPv6 |
| --- | --- | --- |
| アドレス長 | 32ビット | 128ビット |
| 表記 | 10進数をピリオド区切り | 16進数をコロン区切り |
| ヘッダ | 可変長（オプションあり） | **40バイト固定長**。拡張ヘッダで機能を追加し、ルータの処理を簡素化 |
| アドレス自動設定 | 主に DHCP | **SLAAC（ステートレスアドレス自動設定）** も可能 |
| MACアドレスの解決 | ARP | ICMPv6 の **近隣探索（NDP）** |
| セキュリティ | IPsec はオプション | IPsec への対応を前提に設計（実装の必須性は規格改定で緩和） |
| 経路途中での分割（フラグメント） | ルータが行える | 送信元だけが行う |

## IPv4 からの移行技術

IPv4 と IPv6 には互換性がないため、共存させる技術が使われます。

- **デュアルスタック**: 1台の機器が IPv4 と IPv6 の両方を扱う
- **トンネリング**: IPv6 パケットを IPv4 パケットに包んで（カプセル化して）IPv4 網を通す（逆も同様）
- **トランスレーション**: IPv4 と IPv6 のヘッダを相互変換する

## 試験対策のポイント

- **ITパスポート**: 「IPv6 は 128 ビット」「IPv4 アドレス枯渇への対策」であることを押さえる。
- **基本情報**: 表記と省略ルール（`::` は1回だけ）、IPv4 との違い。
- **応用情報**: リンクローカルアドレス、近隣探索、移行技術など、IPv4 との共存環境での動作が問われる。
