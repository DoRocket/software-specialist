IPv4アドレスは約43億個しかなく、世界中の機器すべてに一意のアドレスを割り当てることはできません。
そこで、**組織内（LAN）では自由に使えるプライベートアドレス** を使い、インターネットに出るときだけ **グローバルアドレス** に変換する仕組みが広く使われています。

## グローバルアドレスとプライベートアドレス

| 種類 | 特徴 |
| --- | --- |
| グローバルIPアドレス | インターネット上で一意。管理団体（日本では JPNIC など）から ISP 等を通じて割り当てられる |
| プライベートIPアドレス | 組織内で自由に使える。インターネット上では使えない（ルーティングされない） |

## プライベートアドレスの範囲（RFC 1918）

| 範囲 | CIDR表記 | 旧クラスとの対応 |
| --- | --- | --- |
| 10.0.0.0 〜 10.255.255.255 | 10.0.0.0/8 | クラスA 1個 |
| 172.16.0.0 〜 172.31.255.255 | 172.16.0.0/12 | クラスB 16個 |
| 192.168.0.0 〜 192.168.255.255 | 192.168.0.0/16 | クラスC 256個 |

家庭用ルータの「192.168.1.1」などはこの範囲のアドレスです。

## NAT と NAPT

### NAT（Network Address Translation）

プライベートアドレスとグローバルアドレスを **1対1** で変換します。
同時にインターネットへ出られる端末数は、持っているグローバルアドレスの数までに限られます。

### NAPT（Network Address Port Translation）

IPアドレスに加えて **ポート番号も変換** することで、**1つのグローバルアドレスを複数の端末で共有** します。
IPマスカレードとも呼ばれ、家庭用ルータで一般に使われているのはこちらです。

```
[PC-A 192.168.1.10:50001] ─┐                     ┌─> 203.0.113.5:60001 ─┐
                            ├─ NAPTルータ（変換表）─┤                      ├─> Webサーバ
[PC-B 192.168.1.11:50001] ─┘                     └─> 203.0.113.5:60002 ─┘
```

ルータは変換表（どの内部アドレス:ポートを、どの外部ポートに対応させたか）を保持し、
戻ってきたパケットの宛先ポート番号から元の端末を判別して転送します。

## NAT のメリットと注意点

- **メリット**: グローバルアドレスの節約。内部のアドレス構成を外部から隠せる。
- **注意点**: 外部から内部の機器へ直接通信を開始することは基本的にできない（公開サーバにはポートフォワーディング等の設定が必要）。
  IPアドレスやポート番号をデータ中に含むプロトコルでは、変換によって通信に問題が起きることがある。

## 試験対策のポイント

- **ITパスポート**: 「プライベートIPアドレスは組織内で自由に使え、インターネットとの通信には NAT でグローバルアドレスに変換する」という役割を説明できること。
- **基本情報**: プライベートアドレスの3つの範囲、NAT と NAPT の違い（ポート番号も変換するか）。
- **応用情報**: NAPT の変換表の動き、DMZ に置いた公開サーバへの静的 NAT（ポートフォワーディング）の設定などが、ネットワーク構成の問題で問われる。
