IP によって宛先の **機器** まではパケットが届きます。しかし1台の機器の中では、Webブラウザ、メールソフトなど複数のアプリケーションが同時に通信しています。
トランスポート層は **ポート番号** によって「機器の中のどのアプリケーション宛てか」を識別し、アプリケーション同士の通信を実現します。

代表的なプロトコルは、信頼性を重視する **TCP** と、速さ・軽さを重視する **UDP** の2つです。

## この分野で学ぶこと

- **TCP と UDP** … コネクション型／コネクションレス型の違い、TCP の信頼性を支える仕組み、代表的なポート番号
