会計の言葉は、**「儲けはいくらか（利益）」** と **「財産と借金はいくらあるか（資産・負債・純資産）」** の2つを表すためにあります。
この記事では、会計を初めて学ぶ人のために、売上高・費用・利益・資産・負債・純資産の意味を、架空のお店の1年をたどりながら説明します。
簿記・財務諸表・損益分岐点など、ほかの会計の記事はすべてこの言葉を使います。

## なぜ会計が必要か

お店の財布の中身だけを見ていても、儲かっているかは分かりません。
たとえば、銀行からお金を借りれば財布の中身は増えますが、儲かったわけではありません。
高い機械を買えば財布の中身は大きく減りますが、機械は何年も使えるので、その年だけで大損したと考えるのは不自然です。

会計は、このような **お金の出入り（現金の増減）と、儲け（利益）の違い** を正しく区別して記録・集計するためのルールです。
ルールが共通なので、経営者は前の年と比べられ、銀行や株主は他社と比べられます。

## 儲けを表す言葉: 収益・費用・利益

| 用語 | 意味 | 例（お店の場合） |
| --- | --- | --- |
| **収益** | 商品やサービスを提供して得た、儲けのもとになる価値の増加 | 売上高、受取利息 |
| **売上高** | 本業で商品・サービスを売って得た金額。収益の中心 | 豆やドリンクの代金の合計 |
| **費用** | 収益を得るために使った（消費した）価値 | 売上原価、給料、家賃、水道光熱費、減価償却費、支払利息 |
| **売上原価** | 売れた商品の仕入値（製造業なら製造にかかった原価） | 販売した豆の仕入値 |
| **利益** | 収益から費用を引いた残り。マイナスなら **損失** | — |

$$
\text{利益} = \text{収益} - \text{費用}
$$

ポイントは、**費用は「お金を払ったこと」ではなく「その期の収益のために使ったこと」** で数える点です。

- 仕入れた商品のうち **売れた分だけ** が売上原価（費用）になります。売れ残りは「商品」という財産として次の期に持ち越します。
- 何年も使う設備は、買った年にまとめて費用にせず、使う年数に分けて少しずつ費用にします（**減価償却**）。
- 借りたお金の返済は費用ではありません。借金が減るだけだからです。ただし利息は費用です。

売上高から売上原価だけを引いた額を **売上総利益**（粗利、粗利益）といいます。「商品そのものでいくら稼いだか」を表します。

## 財産を表す言葉: 資産・負債・純資産

| 用語 | 意味 | 例 |
| --- | --- | --- |
| **資産** | 会社が持っている財産。将来お金に換わる、または事業に役立つもの | 現金、預金、売掛金（後で受け取る代金）、商品、建物、設備、ソフトウェア |
| **負債** | 将来お金などで返さなければならない義務（借金など） | 借入金、買掛金（後で支払う代金）、未払金 |
| **純資産** | 資産から負債を引いた残り。返す必要のない、会社自身のもの | 資本金（出資を受けたお金）、これまでの利益の蓄積 |

$$
\text{資産} = \text{負債} + \text{純資産}
$$

この式は、**「持っている財産（左辺）」は「他人から借りたお金」と「自分のお金」のどちらかで手に入れたもの** という意味で、いつでも成り立ちます。
負債は他人資本、純資産は自己資本とも呼ばれます。

利益が出ると、その分だけ純資産が増えます（利益は出資者のものになるため）。
これが、儲けを表す言葉（収益・費用・利益）と、財産を表す言葉（資産・負債・純資産）のつながりです。

## 会計期間

会社は毎日続いているので、どこかで区切らないと「いくら儲かったか」を計算できません。そこで、期間を区切って計算します。

| 用語 | 意味 |
| --- | --- |
| **会計期間** | 利益を計算する期間の単位。ふつうは1年（例: 4月1日〜翌年3月31日） |
| **期首 / 期末** | 会計期間の初日 / 最終日 |
| **当期 / 前期 / 次期** | 今の会計期間 / 1つ前 / 1つ後 |
| **決算** | 期末に1年分の記録を締めくくり、利益と財産の状態を確定させる手続 |

「一定期間の儲け」は **損益計算書**、「ある時点（期末）の財産」は **貸借対照表** という表にまとめます。どちらも詳しくは財務諸表の記事で扱います。

## 事例: 珈琲豆店「こもれび」の1年

架空の小さなお店で、1年間の数字をたどってみます（金額は万円）。こもれびは、焙煎された豆を仕入れて袋詰めで売るお店です。

### 1. 開業する

店主が 300万円を出資して会社を作り、銀行から 200万円を借りました。焙煎機と陳列棚（設備）を 200万円で買いました。

| 資産 | 金額 | 負債・純資産 | 金額 |
| --- | ---: | --- | ---: |
| 現金 | 300 | 借入金（負債） | 200 |
| 設備 | 200 | 資本金（純資産） | 300 |
| 合計 | 500 | 合計 | 500 |

設備を買っても、現金が設備に形を変えただけなので、資産の合計は 500万円のままです。

### 2. 1年間営業する

| 出来事 | 金額 | 会計での扱い |
| --- | ---: | --- |
| 豆やドリンクを売った | 1,200 | 収益（売上高） |
| 豆を仕入れた（うち 40 は期末に売れ残り） | 400 | 売れた 360 が費用（売上原価）、40 は資産（商品） |
| アルバイトの給料を払った | 360 | 費用（人件費） |
| 家賃を払った | 240 | 費用 |
| 水道光熱費などを払った | 60 | 費用 |
| 設備の価値が1年分減った（5年使う予定） | 40 | 費用（減価償却費）。お金は出ていかない |
| 借入金を一部返した | 40 | 費用ではない（負債が減るだけ） |

### 3. 1年間の儲けを計算する（損益計算書の考え方）

| 項目 | 金額 |
| --- | ---: |
| 売上高 | 1,200 |
| 売上原価 | 360 |
| **売上総利益（粗利）** | **840** |
| 人件費・家賃・水道光熱費・減価償却費 | 700 |
| **利益** | **140** |

### 4. 期末の財産を確かめる（貸借対照表の考え方）

現金は $300 + 1{,}200 - 400 - 360 - 240 - 60 - 40 = 400$ 万円、設備は $200 - 40 = 160$ 万円になりました。

| 資産 | 金額 | 負債・純資産 | 金額 |
| --- | ---: | --- | ---: |
| 現金 | 400 | 借入金 | 160 |
| 商品（売れ残り） | 40 | 資本金 | 300 |
| 設備 | 160 | 当期の利益（利益の蓄積） | 140 |
| 合計 | 600 | 合計 | 600 |

左右の合計が一致し、**利益 140万円がそのまま純資産の増加になっている** ことが確かめられます。

### 5. 利益と現金は一致しない

開業時に 500万円あった現金は、1年後に 400万円へ減っています。それでも利益は 140万円の黒字です。
設備の購入（200）、売れ残りの仕入（40）、借入金の返済（40）はお金が出ていきますが当期の費用ではなく、
逆に減価償却費（40）は費用ですがお金は出ていかないためです。

$$
140 + 40 - 40 - 200 - 40 = -100 \text{（万円、現金の増減）}
$$

この「利益と現金の動きの違い」を表すのが、キャッシュフロー計算書です。

## 例題

あるお店の1年間の取引が次のとおりだった。売上総利益と利益（当期の儲け）を求めよ（単位: 万円）。

- 売上高 600、商品の仕入 350（期首の在庫なし、期末の売れ残り 50）
- 給料 120、家賃 60、借入金の返済 30、借入金の利息 5

**解き方**

1. 売上原価 $= 350 - 50 = 300$（売れ残りは費用にしない）
2. 売上総利益 $= 600 - 300 =$ **300万円**
3. 費用に入るのは 給料・家賃・利息。借入金の返済 30 は費用ではない
4. 利益 $= 300 - (120 + 60 + 5) =$ **115万円**

## 試験対策のポイント

- **ip**: 利益・粗利益・売上原価・資産・負債・純資産の意味と、利益の簡単な計算が問われます。
- **fe / ap**: 売上と利益、費用の関係を理解したうえで、損益計算書の段階利益や損益分岐点の計算に進みます。
- **boki3**: 資産・負債・純資産・収益・費用の5つの区分は、仕訳のルールの土台です。どの勘定科目がどの区分に入るかを確実に覚えます。
