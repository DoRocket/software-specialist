**決算** は、会計期間の終わりに1年分の記録を締めくくり、その期の利益と期末の財産を確定させる手続です。
期中の記録（試算表）には、売れ残った商品や設備の価値の減少などがまだ反映されていないので、まず **決算整理** でそれを修正し、
**精算表** で集計してから **損益計算書** と **貸借対照表** を作ります。

## 前提となる用語

仕訳・転記・試算表は前の記事で説明しています。ここでは次の言葉を使います。

| 用語 | 意味 |
| --- | --- |
| **決算整理** | 期中の記録を、期末の正しい状態に合わせるための修正。その仕訳を **決算整理仕訳** という |
| **棚卸（たなおろし）** | 期末に売れ残っている商品の数量と金額を調べること。その金額が **期末商品棚卸高** |
| **繰越商品** | 三分法で、期末に売れ残った商品を次期に繰り越すための資産の勘定 |
| **貸倒れ（かしだおれ）** | 取引先の倒産などで、売掛金などが回収できなくなること |
| **帳簿価額** | 帳簿に記録されている資産の金額（簿価） |

## 決算の流れ

1. **決算整理前残高試算表** を作る（期中の記録の集計）
2. 決算整理事項を調べ、**決算整理仕訳** を行う
3. **精算表** で、試算表 → 修正 → 損益計算書・貸借対照表 への振り分けを一覧にする
4. 収益・費用の勘定を締め切り、当期純利益を **繰越利益剰余金**（純資産）に振り替える
5. **損益計算書** と **貸借対照表** を作成する

## 主な決算整理

### 1. 売上原価の算定

三分法では、期中は仕入れた商品をすべて仕入勘定（費用）に記録しています。しかし費用にすべきなのは **売れた分** だけです。

$$
\text{売上原価} = \text{期首商品棚卸高} + \text{当期商品仕入高} - \text{期末商品棚卸高}
$$

期首の在庫は当期に売れたものとして仕入に加え、期末の売れ残りは仕入から除きます。仕入勘定で売上原価を計算する仕訳は次の2本です。

| 借方科目 | 金額 | 貸方科目 | 金額 | 意味 |
| --- | ---: | --- | ---: | --- |
| 仕入 | 期首商品棚卸高 | 繰越商品 | 期首商品棚卸高 | 期首の在庫を仕入に加える |
| 繰越商品 | 期末商品棚卸高 | 仕入 | 期末商品棚卸高 | 期末の売れ残りを仕入から除く |

勘定科目の頭文字から「しーくり・くりしー」と覚えます。仕訳の後、仕入勘定の残高が売上原価になります。

### 2. 貸倒引当金の設定

期末の売掛金の中には、将来回収できなくなるものがあるかもしれません。
その見込額を当期の費用（**貸倒引当金繰入**）にし、同時に **貸倒引当金**（売掛金から差し引く形で表示する勘定）を設定します。
すでに残高がある場合は、不足する差額だけを繰り入れます（**差額補充法**）。

$$
\text{繰入額} = \text{期末の売掛金} \times \text{設定率} - \text{貸倒引当金の残高}
$$

| 借方科目 | 貸方科目 |
| --- | --- |
| 貸倒引当金繰入 | 貸倒引当金 |

### 3. 減価償却

備品や建物などの固定資産は、使うにつれて価値が減ります。取得原価を使う期間に配分して費用（**減価償却費**）にします。計算方法は「減価償却」の記事で詳しく扱います。

| 記帳方法 | 借方科目 | 貸方科目 | 特徴 |
| --- | --- | --- | --- |
| 間接法 | 減価償却費 | 備品減価償却累計額 | 備品勘定は取得原価のまま残し、減った分を累計額の勘定に積み上げる |
| 直接法 | 減価償却費 | 備品 | 備品勘定の金額を直接減らす |

### 4. 費用の前払い

当期に支払った費用のうち、次期の分が含まれていれば、その分を当期の費用から除いて資産（前払家賃などの前払費用）にします。

| 借方科目 | 貸方科目 |
| --- | --- |
| 前払家賃 | 支払家賃 |

ほかにも、費用・収益の未払い・未収・前受け、現金過不足の整理などの決算整理があります。考え方はどれも「その期に属する収益・費用だけを、その期の損益に入れる」です。

## 精算表

**精算表** は、決算整理前残高試算表から財務諸表までの流れを1枚にまとめた表です。
試算表・修正記入・損益計算書・貸借対照表の4つの欄にそれぞれ借方・貸方があるので **8桁精算表** と呼びます。

| 手順 | すること |
| --- | --- |
| 1 | 試算表欄に、決算整理前残高試算表の金額を写す |
| 2 | 修正記入欄に、決算整理仕訳の金額を書く（新しく出てくる科目は下に追加する） |
| 3 | 試算表欄と修正記入欄を、同じ側なら足し、反対側なら引いて、損益計算書欄（収益・費用）か貸借対照表欄（資産・負債・純資産）に移す |
| 4 | 損益計算書欄の貸借の差額が当期純利益（または当期純損失）。損益計算書欄と貸借対照表欄の反対側にそれぞれ記入して、各欄の貸借をそろえる |

## 事例: こもれび珈琲の決算

株式会社こもれび珈琲（珈琲豆の販売店）の開業2年目の期末（3月31日）です。決算整理事項は次の4つです。

1. 期末商品棚卸高は 250,000円である
2. 売掛金の期末残高に対して 2% の貸倒引当金を差額補充法で設定する
3. 備品（取得原価 800,000円、残存価額 0円、耐用年数 5年）を定額法で減価償却する。記帳は間接法による
4. 支払家賃のうち 80,000円は次期の分である

## よくある失敗と対策

| 失敗 | 対策 |
| --- | --- |
| 期首と期末の商品棚卸高を逆に仕訳する | 「期首は仕入へ足す（仕入／繰越商品）、期末は仕入から引く（繰越商品／仕入）」と意味で覚える |
| 貸倒引当金を差額でなく全額繰り入れる | 決算整理前の貸倒引当金の残高を必ず確認する |
| 精算表で修正記入の加減を誤る | 試算表と同じ側の修正は足し、反対側の修正は引く |
| 当期純利益を貸借対照表欄の借方に書く | 利益は純資産の増加なので、貸借対照表欄では貸方 |

## 試験対策のポイント

- **boki3**: 決算整理仕訳（売上原価の算定、貸倒引当金、減価償却、経過勘定など）と、精算表・財務諸表の作成は出題の中心です。決算整理前残高試算表から最後まで通して解く練習をします。
- **fe / ap**: 試算表・精算表・財務諸表の役割と、決算の目的・仕組みを理解しておきます。
