**仕訳** は、1つの取引を「何が増えて、何が減ったか」の2つの面に分け、勘定科目と金額で左（借方）と右（貸方）に記録することです。
複式簿記のすべての記録は仕訳から始まり、元帳・試算表・財務諸表はこの仕訳を集計して作られます。
この記事では、仕訳のルールを基礎から説明し、架空のお店の1か月の取引を実際に仕訳してみます。

## 前提となる用語

資産・負債・純資産・収益・費用の意味は「会計の基本用語」で説明しています。ここでは次の言葉を使います。

| 用語 | 意味 |
| --- | --- |
| **借方（かりかた）** | 仕訳や勘定の **左側**。「借りる」という意味はない |
| **貸方（かしかた）** | 仕訳や勘定の **右側**。「貸す」という意味はない |
| **勘定科目** | 記録の分類の名前（現金、売掛金、売上など） |
| **掛け（かけ）** | 代金を後で支払う・受け取る約束で売買すること。後で受け取る権利が **売掛金**、後で支払う義務が **買掛金** |

## 仕訳の形

仕訳は、借方の勘定科目と金額、貸方の勘定科目と金額を並べて書きます。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 現金 | 30,000 | 売上 | 30,000 |

これは「商品を 30,000円で売り、代金を現金で受け取った」取引です。現金（資産）が増えた面を借方に、売上（収益）が生じた面を貸方に書いています。
文章では「（借）現金 30,000 （貸）売上 30,000」とも書きます。**借方の合計と貸方の合計は必ず同じ金額** になります。

## 5要素と、増減を書く側のルール

勘定科目はすべて、資産・負債・純資産・収益・費用のどれかに属します。
それぞれ **「増えたとき（発生したとき）に書く側」** が決まっていて、減ったときはその反対側に書きます。

| 要素 | 増加（発生）は | 減少（取消）は | 覚え方 |
| --- | --- | --- | --- |
| **資産** | 借方（左） | 貸方（右） | 貸借対照表の左側にある |
| **負債** | 貸方（右） | 借方（左） | 貸借対照表の右側にある |
| **純資産** | 貸方（右） | 借方（左） | 貸借対照表の右側にある |
| **費用** | 借方（左） | 貸方（右） | 損益計算書の左側にある |
| **収益** | 貸方（右） | 借方（左） | 損益計算書の右側にある |

貸借対照表と損益計算書を左右に並べた図で、**その要素がある側が「増加」の側** と覚えます。

| 貸借対照表の借方 | 貸借対照表の貸方 | 損益計算書の借方 | 損益計算書の貸方 |
| --- | --- | --- | --- |
| 資産 | 負債 / 純資産 | 費用 | 収益 |

## 取引の8要素の結合関係

5要素の増減を左右に分けると、借方に来るもの4つ、貸方に来るもの4つの合計8つになります（**取引の8要素**）。
どの取引も、借方の要素と貸方の要素の組合せで表されます。

| 借方（左）に来るもの | 貸方（右）に来るもの |
| --- | --- |
| 資産の増加 | 資産の減少 |
| 負債の減少 | 負債の増加 |
| 純資産の減少 | 純資産の増加 |
| 費用の発生 | 収益の発生 |

組合せの例:

| 取引 | 借方の要素 | 貸方の要素 |
| --- | --- | --- |
| 銀行から現金を借りた | 資産（現金）の増加 | 負債（借入金）の増加 |
| 備品を現金で買った | 資産（備品）の増加 | 資産（現金）の減少 |
| 給料を現金で払った | 費用（給料）の発生 | 資産（現金）の減少 |
| 買掛金を現金で払った | 負債（買掛金）の減少 | 資産（現金）の減少 |
| 株式を発行し出資を受けた | 資産（現金）の増加 | 純資産（資本金）の増加 |

## 主な勘定科目

| 区分 | 勘定科目の例 |
| --- | --- |
| 資産 | 現金、普通預金、当座預金、売掛金、繰越商品、貸付金、前払金、未収入金、建物、備品、車両運搬具、土地 |
| 負債 | 買掛金、借入金、未払金、前受金、預り金 |
| 純資産 | 資本金、繰越利益剰余金 |
| 収益 | 売上、受取利息、受取手数料、受取家賃 |
| 費用 | 仕入、給料、支払家賃、水道光熱費、通信費、消耗品費、旅費交通費、支払利息、減価償却費 |

似た名前の科目は、何の取引から生じたかで使い分けます。

- **売掛金 / 未収入金**: 商品を売った代金の未収は売掛金、それ以外（不要になった備品の売却代金など）の未収は未収入金
- **買掛金 / 未払金**: 商品の仕入代金の未払いは買掛金、それ以外（備品の購入代金など）の未払いは未払金

### 商品売買の記録（三分法）

商品の売買は、**仕入**（費用）・**売上**（収益）・**繰越商品**（資産）の3つの勘定で記録する方法が一般的で、これを **三分法** といいます。
期中は、仕入れたら仕入勘定の借方、売ったら売上勘定の貸方に、それぞれ仕入値・売値で記録します。
売れ残った商品を繰越商品に振り替える処理は、期末の決算整理で行います。

## 実際の進め方: 仕訳を考える手順

1. **何が動いたかを言葉にする**: 「現金が減って、備品が増えた」
2. **勘定科目を決める**: 現金、備品
3. **5要素のどれかを判定する**: 現金も備品も資産
4. **増減と左右を決める**: 備品（資産）の増加 → 借方、現金（資産）の減少 → 貸方
5. **金額を書き、貸借の合計が一致することを確かめる**

| よくある失敗 | 対策 |
| --- | --- |
| 「借方 = 借りたもの」と考えて逆に書く | 借方・貸方は左右の名前と割り切る。5要素の表で判断する |
| 借入金の返済額を費用にする | 返済は負債の減少。費用になるのは利息だけ |
| 備品の購入代金の未払いを買掛金にする | 買掛金は商品の仕入代金だけ。それ以外は未払金 |
| 複合仕訳で金額の合計が合わない | 最後に借方合計と貸方合計を必ず比べる |

## 事例: こもれび珈琲の4月の仕訳

珈琲豆を仕入れて販売する架空の会社「株式会社こもれび珈琲」の、開業した月の取引です。

| 日付 | 取引 |
| --- | --- |
| 4/1 | 株式を発行し、現金 3,000,000円の出資を受けて開業した |
| 4/2 | 銀行から現金 1,000,000円を借り入れた |
| 4/3 | 焙煎機と陳列棚（備品）を 800,000円で購入し、現金で支払った |
| 4/6 | 商品（珈琲豆）400,000円を仕入れ、代金は掛けとした |
| 4/10 | 商品を 300,000円で売り上げ、100,000円は現金で受け取り、残りは掛けとした |
| 4/20 | 売掛金のうち 150,000円を現金で回収した |
| 4/25 | 給料 120,000円を現金で支払った |
| 4/25 | 店舗の家賃 80,000円を現金で支払った |
| 4/30 | 買掛金のうち 250,000円を現金で支払った |
| 4/30 | 借入金のうち 100,000円を、利息 5,000円とともに現金で返済した |

仕訳は次のとおりです。

| 日付 | 借方科目 | 金額 | 貸方科目 | 金額 | 考え方 |
| --- | --- | ---: | --- | ---: | --- |
| 4/1 | 現金 | 3,000,000 | 資本金 | 3,000,000 | 資産の増加 / 純資産の増加 |
| 4/2 | 現金 | 1,000,000 | 借入金 | 1,000,000 | 資産の増加 / 負債の増加 |
| 4/3 | 備品 | 800,000 | 現金 | 800,000 | 資産の増加 / 資産の減少 |
| 4/6 | 仕入 | 400,000 | 買掛金 | 400,000 | 費用の発生 / 負債の増加 |
| 4/10 | 現金 | 100,000 | 売上 | 300,000 | 資産の増加（2科目）/ 収益の発生 |
| | 売掛金 | 200,000 | | | |
| 4/20 | 現金 | 150,000 | 売掛金 | 150,000 | 資産の増加 / 資産の減少 |
| 4/25 | 給料 | 120,000 | 現金 | 120,000 | 費用の発生 / 資産の減少 |
| 4/25 | 支払家賃 | 80,000 | 現金 | 80,000 | 費用の発生 / 資産の減少 |
| 4/30 | 買掛金 | 250,000 | 現金 | 250,000 | 負債の減少 / 資産の減少 |
| 4/30 | 借入金 | 100,000 | 現金 | 105,000 | 負債の減少・費用の発生 / 資産の減少 |
| | 支払利息 | 5,000 | | | |

ポイント:

- 4/3 の備品の購入は、資産どうしの入れ替えなので利益に影響しません。
- 4/10 と 4/30（2つ目）は、一方の側に2つの科目が並ぶ **複合仕訳** です。どちらも借方合計と貸方合計が一致しています。
- 4/20 の売掛金の回収は、売上を計上した 4/10 とは別の取引です。回収したときに売上を再び記録しないよう注意します。

これらの仕訳を勘定科目ごとに集めて、残高を確かめるのが次の「転記と試算表」です。

## 例題

次の取引を仕訳せよ。

1. 事務用の机（備品）150,000円を購入し、代金は月末に支払うことにした。
2. 商品 60,000円を売り上げ、代金は掛けとした。
3. 銀行の普通預金口座に、現金 200,000円を預け入れた。

**解き方**

1. 備品（資産）の増加 / 商品以外の代金の未払いなので未払金（負債）の増加 → （借）備品 150,000 （貸）未払金 150,000
2. 売掛金（資産）の増加 / 売上（収益）の発生 → （借）売掛金 60,000 （貸）売上 60,000
3. 普通預金（資産）の増加 / 現金（資産）の減少 → （借）普通預金 200,000 （貸）現金 200,000

## 試験対策のポイント

- **boki3**: 仕訳は出題の中心です。5要素の増減ルールを確実にし、似た勘定科目（売掛金と未収入金、買掛金と未払金など）の使い分けを、取引の文章から判断できるようにします。
- **fe / ap**: シラバスの「企業会計の手順」として、取引を仕訳で記録し、仕訳帳・総勘定元帳を経て決算に至る流れの理解が求められます。
