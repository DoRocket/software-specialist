仕訳は取引の発生順に並んでいるので、そのままでは「現金がいま全部でいくらあるか」が分かりません。
そこで、仕訳を勘定科目ごとの口座（**勘定**）に書き写して集計します。これを **転記** といい、勘定を集めた帳簿を **総勘定元帳** といいます。
さらに、すべての勘定の金額を1つの表にまとめた **試算表** を作り、記録に誤りがないかを確かめます。

## 前提となる用語

仕訳・借方・貸方・勘定科目は「仕訳と勘定科目」で説明しています。ここでは次の言葉を使います。

| 用語 | 意味 |
| --- | --- |
| **勘定** | 勘定科目ごとに増減を記録する口座 |
| **T字勘定** | 勘定を、左（借方）と右（貸方）に分けた T の字の形で簡略に書いたもの。学習や下書きで使う |
| **相手科目** | 仕訳でその科目と反対側にある科目。転記のとき「何と引き換えに増減したか」として書く |
| **残高** | 勘定の借方合計と貸方合計の差。多い側に残る |

## 転記のルール

1. 仕訳の **借方** の科目は、その勘定の **借方** に書く
2. 仕訳の **貸方** の科目は、その勘定の **貸方** に書く
3. 書く内容は **日付・相手科目・金額**。相手科目が2つ以上あるときは「**諸口**（しょくち）」と書く

たとえば「（借）現金 3,000,000 （貸）資本金 3,000,000」を転記すると、次のようになります。

| 勘定 | 借方 | 貸方 |
| --- | --- | --- |
| 現金 | 4/1 資本金 3,000,000 | |
| 資本金 | | 4/1 現金 3,000,000 |

実際の総勘定元帳は、日付・摘要（相手科目）・仕丁（その仕訳が書かれた仕訳帳のページ番号）・借方金額・貸方金額などの欄を持つ表の形で、
残高の欄を設けたもの（残高式）もあります。考え方は T字勘定と同じです。

## 勘定の残高

各勘定の借方合計と貸方合計の差が残高です。5要素ごとに、ふつう残高が出る側が決まっています（増加を書く側と同じ）。

| 要素 | ふつうの残高 |
| --- | --- |
| 資産・費用 | 借方残高 |
| 負債・純資産・収益 | 貸方残高 |

たとえば現金勘定は、借方合計 $3{,}000{,}000 + 1{,}000{,}000 + 100{,}000 + 150{,}000 = 4{,}250{,}000$、
貸方合計 $800{,}000 + 120{,}000 + 80{,}000 + 250{,}000 + 105{,}000 = 1{,}355{,}000$ なので、
残高は $4{,}250{,}000 - 1{,}355{,}000 = 2{,}895{,}000$ 円の借方残高です。

## 試算表の種類

| 種類 | 載せるもの | 特徴 |
| --- | --- | --- |
| **合計試算表** | 各勘定の借方合計と貸方合計 | 総額は仕訳帳の金額の合計と一致する |
| **残高試算表** | 各勘定の残高 | 財務諸表の作成にそのまま使いやすい |
| **合計残高試算表** | 合計と残高の両方 | 上の2つを1つにまとめたもの |

どの試算表も、借方の合計と貸方の合計は必ず一致します。すべての仕訳で借方と貸方が同額だからです（貸借平均の原理）。

## 実際の進め方

1. 仕訳を1件ずつ、借方の科目は勘定の借方へ、貸方の科目は勘定の貸方へ転記する
2. 勘定ごとに借方合計・貸方合計を出し、差を残高とする
3. 試算表の様式に、勘定科目を資産 → 負債 → 純資産 → 収益 → 費用 の順に並べて金額を書く
4. 借方合計と貸方合計を比べる。一致しなければ、試算表の計算 → 元帳の集計 → 転記 → 仕訳 の順にさかのぼって探す

## 試算表で見つけられる誤り・見つけられない誤り

| 見つけられる（貸借が一致しなくなる） | 見つけられない（貸借は一致したまま） |
| --- | --- |
| 借方か貸方の一方だけを転記した | 取引の仕訳そのものをもらした |
| 一方の金額を書き間違えた | 同じ仕訳を2回転記した |
| 一方を反対側（借方を貸方）に転記した | 勘定科目を誤った（現金を普通預金にした など） |
| 残高の計算を間違えた | 借方と貸方を両方とも同じ金額だけ間違えた |

試算表は便利な点検手段ですが、一致したからといって記録が正しいとは限りません。

## 事例: こもれび珈琲の4月の試算表

図の転記結果から、合計残高試算表を作ります（単位: 円）。

| 借方残高 | 借方合計 | 勘定科目 | 貸方合計 | 貸方残高 |
| ---: | ---: | :---: | ---: | ---: |
| 2,895,000 | 4,250,000 | 現金 | 1,355,000 | |
| 50,000 | 200,000 | 売掛金 | 150,000 | |
| 800,000 | 800,000 | 備品 | | |
| | 250,000 | 買掛金 | 400,000 | 150,000 |
| | 100,000 | 借入金 | 1,000,000 | 900,000 |
| | | 資本金 | 3,000,000 | 3,000,000 |
| | | 売上 | 300,000 | 300,000 |
| 400,000 | 400,000 | 仕入 | | |
| 120,000 | 120,000 | 給料 | | |
| 80,000 | 80,000 | 支払家賃 | | |
| 5,000 | 5,000 | 支払利息 | | |
| **4,350,000** | **6,205,000** | 合計 | **6,205,000** | **4,350,000** |

- 合計の欄の 6,205,000円は、4月の10の仕訳の金額（借方側）をすべて足した額と一致します。
- 残高の欄の 4,350,000円も、借方と貸方で一致しました。

この試算表を見ると、売上 300,000円に対して仕入が 400,000円あります。これは損をしたのではなく、仕入れた商品の一部がまだ売れ残っているためです。
売れ残った分を費用から除く処理は、期末の決算で行います。

## 例題

次の T字勘定の残高を求めよ（単位: 円）。

- 売掛金勘定: 借方 4/5 売上 120,000、4/18 売上 90,000 / 貸方 4/25 現金 150,000
- 買掛金勘定: 借方 4/28 現金 70,000 / 貸方 4/3 仕入 100,000、4/15 仕入 60,000

**解き方**

1. 売掛金: 借方合計 $120{,}000 + 90{,}000 = 210{,}000$、貸方合計 150,000 → **借方残高 60,000円**（まだ回収していない代金）
2. 買掛金: 借方合計 70,000、貸方合計 $100{,}000 + 60{,}000 = 160{,}000$ → **貸方残高 90,000円**（まだ支払っていない代金）
