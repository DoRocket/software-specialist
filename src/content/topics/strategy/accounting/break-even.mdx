**損益分岐点分析** は、費用を「売上に比例して増える費用」と「売上に関係なくかかる費用」に分けて、
**いくら売れば赤字にならないか（利益が 0 になる売上高）** を求める分析です。
「値下げしても利益は出るか」「設備を入れて固定費が増えたら、どれだけ売ればよいか」といった経営判断に使います。
費用（Cost）・販売量（Volume）・利益（Profit）の関係を見るので **CVP 分析** とも呼ばれ、社内の意思決定に使う管理会計の代表的な手法です。

## 前提となる用語

売上高・費用・利益の意味は「会計の基本用語」で説明しています。ここでは費用を次の2つに分けます。

| 用語 | 意味 | 例（小売店の場合） |
| --- | --- | --- |
| **変動費** | 売上高（販売量）に比例して増減する費用 | 商品の仕入原価、販売手数料、配送費 |
| **固定費** | 売上高にかかわらず一定額かかる費用 | 家賃、正社員の給料、減価償却費、保険料 |
| **変動費率** | 売上高に占める変動費の割合 | 変動費 ÷ 売上高 |
| **限界利益** | 売上高 − 変動費。固定費を回収し、利益を生む元手 | — |
| **限界利益率** | 売上高に占める限界利益の割合（$1 - $ 変動費率） | — |

## 仕組み

売上高を $S$、変動費率を $v$、固定費を $F$ とすると、利益は次のように表せます。

$$
\text{利益} = S - (vS + F) = (1 - v)S - F
$$

利益が 0 になる売上高が **損益分岐点売上高** です。上の式を 0 とおいて解くと次の公式になります。

$$
\def\arraystretch{2.2}
\begin{array}{ll}
\text{変動費率} &{}= \dfrac{\text{変動費}}{\text{売上高}} \\
\text{損益分岐点売上高} &{}= \dfrac{\text{固定費}}{1 - \text{変動費率}} = \dfrac{\text{固定費}}{\text{限界利益率}} \\
\text{目標利益を達成する売上高} &{}= \dfrac{\text{固定費} + \text{目標利益}}{1 - \text{変動費率}}
\end{array}
$$

意味で言い換えると、「売上 1円あたり $(1 - v)$ 円が固定費の回収に回るので、固定費をすべて回収できる売上高が損益分岐点」です。

この考え方に合わせて、「売上高 − 変動費 = 限界利益」「限界利益 − 固定費 = 営業利益」の順に並べた損益計算書を **変動損益計算書** といいます。
通常の損益計算書（売上原価・販管費で区分）とは費用の分け方が違い、社内の分析に使います。

販売量で考える場合は、1個あたりの限界利益（販売単価 − 1個あたりの変動費）で割ります。
たとえば販売単価 2,000円、1個あたりの変動費 1,200円、固定費 400万円なら、損益分岐点の販売量は $\dfrac{4{,}000{,}000}{2{,}000 - 1{,}200} = 5{,}000$ 個です。

### 損益分岐点図表

横軸に売上高、縦軸に金額をとり、**売上高線**（原点を通る 45° の線）と **総費用線**（固定費の高さから始まり、傾きが変動費率の線）を描くと、
2つの線の交点が損益分岐点です。交点より右では売上高線が上にあるので利益、左では総費用線が上にあるので損失になります。

固定費・変動費率・売上高を動かして、損益分岐点と利益がどう変わるかを確かめてください。

- **固定費を増やす** と、総費用線が上に平行移動し、損益分岐点は右（大きい売上高）へ動きます。
- **変動費率を上げる** と、総費用線の傾きが急になり、損益分岐点は右へ動きます。
- 売上高を動かしても損益分岐点は変わりません。変わるのは、損益分岐点からどれだけ離れているか（安全余裕率）と利益です。

## 安全性を表す指標

| 指標 | 計算式 | 意味 |
| --- | --- | --- |
| **安全余裕率** | $\dfrac{\text{売上高} - \text{損益分岐点売上高}}{\text{売上高}} \times 100$ | 売上高があと何%減ると赤字になるか。高いほど安全 |
| **損益分岐点比率** | $\dfrac{\text{損益分岐点売上高}}{\text{売上高}} \times 100$ | 今の売上高に対する損益分岐点の位置。低いほど安全 |

2つの指標の合計は 100% になります。

## 固定費と変動費の分け方

実際の会社の費用は、損益計算書の勘定科目ごとに記録されていて、「固定費」「変動費」とは書かれていません。分析の前に分ける必要があります。

| 方法 | やり方 | 特徴 |
| --- | --- | --- |
| **勘定科目法**（費目別精査法） | 勘定科目ごとに、固定費か変動費かを判断して振り分ける | 簡単で早い。判断に迷う費用（電気代など）は主観が入る |
| **高低点法** | 売上高が最も高い期と最も低い期の2点から、変動費率と固定費を求める | 計算が簡単。2点しか使わないので、異常な月を選ぶとずれる |

高低点法の計算は次のとおりです。

$$
\def\arraystretch{2.2}
\begin{array}{ll}
\text{変動費率} &{}= \dfrac{\text{最高の月の総費用} - \text{最低の月の総費用}}{\text{最高の月の売上高} - \text{最低の月の売上高}} \\
\text{固定費} &{}= \text{総費用} - \text{売上高} \times \text{変動費率}
\end{array}
$$

電気代のように、基本料金（固定費）と使用量に応じた料金（変動費）を両方含む費用を **準変動費** といいます。勘定科目法で分ける場合は、どちらの性質が強いかで割り振るか、内訳を分けて扱います。

## 実際の進め方

1. **期間を決めて費用を集める**: 直近1年の損益計算書の費用を勘定科目ごとに並べる
2. **固定費と変動費に分ける**: 勘定科目法で振り分け、迷うものは過去の月次データで高低点法などを使って確かめる
3. **変動費率と損益分岐点を計算する**: 変動費 ÷ 売上高、固定費 ÷ (1 − 変動費率)
4. **安全余裕率を見る**: 今の売上高が損益分岐点からどれだけ離れているか
5. **打ち手を比べる**: 値下げ、仕入先の変更（変動費率）、設備投資や人員の増減（固定費）のそれぞれで、損益分岐点と利益がどう変わるかを計算する

ワークシートの形にすると、次のようになります。

| 項目 | 現状 | 案A | 案B |
| --- | ---: | ---: | ---: |
| 売上高 | | | |
| 変動費（変動費率） | | | |
| 限界利益（限界利益率） | | | |
| 固定費 | | | |
| 利益 | | | |
| 損益分岐点売上高 | | | |
| 安全余裕率 | | | |

| よくある失敗 | 対策 |
| --- | --- |
| 値下げしたのに変動費率を変えずに計算する | 値下げすると売上高に占める仕入原価の割合が上がる。単価ベースで変動費率を計算し直す |
| 固定費は「絶対に変わらない費用」と考える | 一定の販売量の範囲でのみ固定。大きく増産すれば設備や人員が必要になり、固定費も増える |
| 損益分岐点だけを見て判断する | 安全余裕率や目標利益の売上高、市場が実際にどこまで買ってくれるかも合わせて見る |

## 事例: こもれび珈琲の値下げと設備投資

「会計の基本用語」の事例に出てきた珈琲豆店こもれびの1年間を、損益分岐点で分析します（単位: 万円）。

**現状の分析**

| 項目 | 金額 | 区分 |
| --- | ---: | --- |
| 売上高 | 1,200 | — |
| 売上原価（豆の仕入値） | 360 | 変動費（変動費率 $360 \div 1{,}200 = 30\%$） |
| 人件費・家賃・水道光熱費・減価償却費 | 700 | 固定費として扱う |
| 利益 | 140 | — |

- 損益分岐点売上高 $= \dfrac{700}{1 - 0.3} = 1{,}000$ 万円
- 安全余裕率 $= \dfrac{1{,}200 - 1{,}000}{1{,}200} \approx 16.7\%$

売上があと 16.7% 減ると赤字になります。

**案A: 全商品を 10% 値下げして客数を増やす**

仕入値は変わらないので、売上高に占める仕入原価の割合が上がります。値下げ後の変動費率は $\dfrac{0.3}{0.9} = \dfrac{1}{3}$ です。
今と同じ利益 140万円を確保するための売上高は、次のとおりです。

$$
\frac{700 + 140}{1 - \frac{1}{3}} = \frac{840}{\frac{2}{3}} = 1{,}260 \text{ 万円}
$$

値下げ後の価格で 1,260万円を売るには、販売量を $\dfrac{1{,}260}{0.9} \div 1{,}200 = 1{,}400 \div 1{,}200 \approx 1.17$ 倍、つまり約 17% 増やす必要があります。
「10% の値下げなら、10% 多く売れれば元が取れる」とはならない点が重要です。

**案B: 焙煎機を導入して自家焙煎にする**

生豆を仕入れて自分で焙煎すると、仕入原価が下がり変動費率は 25% になります。一方、焙煎機の減価償却費や保守費用で固定費が年 60万円増えます。

| 項目 | 現状 | 案B |
| --- | ---: | ---: |
| 固定費 | 700 | 760 |
| 変動費率 | 30% | 25% |
| 損益分岐点売上高 | 1,000 | $760 \div 0.75 \approx 1{,}013.3$ |
| 売上高 1,200 のときの利益 | 140 | $1{,}200 \times 0.75 - 760 = 140$ |
| 売上高 1,500 のときの利益 | $1{,}500 \times 0.7 - 700 = 350$ | $1{,}500 \times 0.75 - 760 = 365$ |

2つの案の利益が等しくなる売上高は、$0.7S - 700 = 0.75S - 760$ より $S = 1{,}200$ 万円です。
**売上高が 1,200万円を超える見込みなら案Bが有利、下回るなら現状のほうが有利** です。
固定費を増やして変動費率を下げる投資は、売上が伸びるほど効果が大きくなる一方、売上が落ちたときの損失も大きくなります。

## 例題

売上高 1,000万円、変動費 600万円、固定費 300万円の企業がある。損益分岐点売上高と、利益を 200万円にするための売上高を求めよ。

**解き方**

1. 変動費率 $= \dfrac{600}{1{,}000} = 0.6$、限界利益率 $= 1 - 0.6 = 0.4$
2. 損益分岐点売上高 $= \dfrac{300}{0.4} =$ **750万円**
3. 目標利益 200万円の売上高 $= \dfrac{300 + 200}{0.4} =$ **1,250万円**

確認: $1{,}250 \times 0.4 - 300 = 200$（万円）となり、正しいことがわかります。このときの安全余裕率は $\dfrac{1{,}000 - 750}{1{,}000} = 25\%$ です。

## 試験対策のポイント

- **ip**: 損益分岐点売上高の計算が頻出です。変動費率 → 限界利益率 → 固定費 ÷ 限界利益率 の順で解きます。
- **fe**: 目標利益を達成する売上高、固定費・変動費率が変化したときの損益分岐点の変化が問われます。
- **ap**: 安全余裕率・損益分岐点比率、変動損益計算書、固定費と変動費の分解など、損益分岐点を使った分析・比較が出題されます。
