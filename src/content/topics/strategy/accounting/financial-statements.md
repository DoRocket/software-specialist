**財務諸表** は、会社の1年間の成績と期末の財産の状態を、決まった形式でまとめた報告書です。
代表的なものは **損益計算書**（どれだけ儲けたか）、**貸借対照表**（財産と借金がどれだけあるか）、**キャッシュフロー計算書**（現金がどう動いたか）の3つで、
この記事ではそれぞれの構造と、数字を比べて会社の状態を判断する **財務指標** の使い方を説明します。

## 前提となる用語

売上高・売上原価・費用・利益、資産・負債・純資産の意味は「会計の基本用語」で説明しています。ここでは次の言葉も使います。

| 用語 | 意味 |
| --- | --- |
| 販売費及び一般管理費（販管費） | 商品を売るための費用と、会社を運営するための費用。給料、広告費、家賃、減価償却費など |
| 営業外収益 / 営業外費用 | 本業以外で、毎期くり返し発生するもの。受取利息、支払利息など |
| 特別利益 / 特別損失 | その期だけの臨時的なもの。固定資産売却益・売却損、災害による損失など |
| 法人税等 | 利益にかかる税金（法人税、住民税及び事業税） |

## 損益計算書（P/L）

一定期間の **経営成績** を表します。英語の Profit and Loss statement から P/L とも呼びます。
利益を一度に計算せず、性質ごとに5段階に分けて計算するのが特徴です。

| 計算 | 利益 | 読み取れること |
| --- | --- | --- |
| 売上高 − 売上原価 | **売上総利益**（粗利） | 商品・サービスそのものの稼ぐ力 |
| 売上総利益 − 販売費及び一般管理費 | **営業利益** | 本業の儲け |
| 営業利益 + 営業外収益 − 営業外費用 | **経常利益** | 借入金の利息なども含めた、ふだんの活動による儲け |
| 経常利益 + 特別利益 − 特別損失 | **税引前当期純利益** | 臨時の出来事も含めた儲け |
| 税引前当期純利益 − 法人税等 | **当期純利益** | 最終的に株主のものになる儲け |

段階に分けることで、「本業は好調だが借入金の利息が重い（営業利益は大きいが経常利益が小さい）」
「本業は普通だが、工場を売った利益で最終利益が大きく見える（特別利益が大きい）」といった違いが分かります。

## 貸借対照表（B/S）

ある時点（期末）の **財政状態** を表します。英語の Balance Sheet から B/S とも呼びます。
右側（**貸方**）にお金をどう集めたか、左側（**借方**）に集めたお金を何に使っているかを書きます。

| 借方（左側）: 資金の運用 | 貸方（右側）: 資金の調達 |
| --- | --- |
| **流動資産**: 現金預金、売掛金、商品など、短期間で現金になるもの | **流動負債**: 買掛金、短期借入金など、短期間で支払うもの |
| **固定資産**: 建物、設備（有形固定資産）、ソフトウェア（無形固定資産）など、長く使うもの | **固定負債**: 長期借入金、社債など、返済が先のもの |
| （繰延資産: 創立費など、効果が将来に及ぶとして資産に計上できる一部の支出） | **純資産**: 資本金、利益剰余金（これまでの利益の蓄積）など |

常に **資産 = 負債 + 純資産** が成り立ちます。
流動と固定は、おおむね「1年以内に現金になる（支払う）か」で分けます（1年基準）。
ただし、売掛金や買掛金のように本業の取引の流れで生じるものは、期間にかかわらず流動に入れます（正常営業循環基準）。

## キャッシュフロー計算書（C/F）

一定期間の **現金の出入り** を、活動の種類ごとに3つに分けて表します。
利益が出ていても、売掛金の回収が遅れたり設備投資が重なったりすると現金は足りなくなるため、損益計算書とは別に作ります。

| 区分 | 主な内容 | 健全な会社でよく見られる符号 |
| --- | --- | --- |
| **営業活動** によるキャッシュフロー | 商品の販売による収入、仕入・給料などの支出 | プラス（本業で現金を生んでいる） |
| **投資活動** によるキャッシュフロー | 設備・ソフトウェアの購入による支出、設備の売却による収入 | マイナス（将来のために投資している） |
| **財務活動** によるキャッシュフロー | 借入れ・株式の発行による収入、借入金の返済・配当金の支払い | 状況による |

営業キャッシュフローと投資キャッシュフローの合計を **フリーキャッシュフロー** といい、借入金の返済や配当に自由に使える現金の目安になります。

## 財務指標

財務諸表の数字は、金額そのものより **比率にして比べる** と、規模の違う会社どうしや過去の年と比較できます。

| 観点 | 指標 | 計算式 | 意味 |
| --- | --- | --- | --- |
| 安全性（短期） | 流動比率 | $\dfrac{\text{流動資産}}{\text{流動負債}} \times 100$ | 短期の支払能力。高いほど安全（目安として 200% 以上が望ましいとされる） |
| 安全性（短期） | 当座比率 | $\dfrac{\text{当座資産}}{\text{流動負債}} \times 100$ | 当座資産は現金預金・売掛金など、すぐ現金になるもの。在庫を除いた厳しめの支払能力 |
| 安全性（長期） | 自己資本比率 | $\dfrac{\text{自己資本}}{\text{総資本}} \times 100$ | 総資本（負債 + 純資産）のうち返済不要な資金の割合。高いほど安定 |
| 安全性（長期） | 固定比率 | $\dfrac{\text{固定資産}}{\text{自己資本}} \times 100$ | 長く使う資産を自己資本でまかなえているか。低いほど安全 |
| 収益性 | 売上高営業利益率 | $\dfrac{\text{営業利益}}{\text{売上高}} \times 100$ | 本業の利益率 |
| 収益性 | ROE（自己資本利益率） | $\dfrac{\text{当期純利益}}{\text{自己資本}} \times 100$ | 株主の資金でどれだけ利益を上げたか |
| 収益性 | ROA（総資産利益率） | $\dfrac{\text{利益}}{\text{総資産}} \times 100$ | 会社の資産全体でどれだけ利益を上げたか。分子の利益（当期純利益・経常利益など）は目的や問題文に従う |
| 効率性 | 総資本回転率 | $\dfrac{\text{売上高}}{\text{総資本}}$（回） | 資本を何回転させて売上を上げたか |

ROE は次のように3つに分解できます。どこが ROE を押し上げているかが分かります。

$$
\text{ROE} = \frac{\text{当期純利益}}{\text{売上高}} \times \frac{\text{売上高}}{\text{総資本}} \times \frac{\text{総資本}}{\text{自己資本}}
$$

1つ目は売上高当期純利益率（収益性）、2つ目は総資本回転率（効率性）、3つ目は財務レバレッジ（借入れの多さ）です。
借入れを増やすと自己資本が相対的に小さくなり ROE は上がりますが、自己資本比率は下がるので、ROE だけで良し悪しを決めないようにします。

## 実際の進め方

財務諸表を読むときは、次の順に進めると迷いません。

1. **規模をつかむ**: 売上高・総資産・純資産のおおよその大きさを見る
2. **P/L を上から読む**: 段階利益のどこで大きく減っているか（原価が高いのか、販管費が多いのか、利息が重いのか、臨時の損失か）
3. **B/S で安全性を見る**: 流動比率・自己資本比率・固定比率を計算する
4. **C/F で現金の裏付けを見る**: 営業キャッシュフローがプラスか、利益と大きくずれていないか
5. **比較する**: 前の年、同業他社、業界の平均と比べる。1社1年分の数字だけで良し悪しを決めない

よくある失敗は、利益だけを見て「黒字だから安全」と判断することです。黒字でも現金が尽きれば支払いができなくなります（黒字倒産）。

## 事例: 株式会社ミナトソフトの決算を読む

受託開発と自社のクラウドサービスを手がける架空の会社、ミナトソフトの当期の財務諸表です（単位: 百万円）。

**損益計算書**

| 項目 | 金額 |
| --- | ---: |
| 売上高 | 1,000 |
| 売上原価 | 600 |
| 売上総利益 | 400 |
| 販売費及び一般管理費 | 250 |
| 営業利益 | 150 |
| 営業外収益 / 営業外費用 | 10 / 20 |
| 経常利益 | 140 |
| 特別損失（旧システムの除却損） | 40 |
| 税引前当期純利益 | 100 |
| 法人税等 | 30 |
| 当期純利益 | 70 |

**貸借対照表（期末）**

| 資産 | 金額 | 負債・純資産 | 金額 |
| --- | ---: | --- | ---: |
| 現金預金 | 200 | 買掛金 | 100 |
| 売掛金 | 250 | 短期借入金 | 150 |
| 仕掛品などの棚卸資産 | 50 | （流動負債 計） | 250 |
| （流動資産 計） | 500 | 長期借入金（固定負債） | 150 |
| 有形固定資産（サーバ等） | 200 | 資本金 | 100 |
| 無形固定資産（ソフトウェア） | 100 | 利益剰余金 | 300 |
| （固定資産 計） | 300 | （純資産 計） | 400 |
| 資産合計 | 800 | 負債・純資産合計 | 800 |

**キャッシュフロー計算書**: 営業 +120、投資 −80（サーバとソフトウェアへの投資）、財務 −20（借入金の返済）

**分析**

| 指標 | 計算 | 結果 |
| --- | --- | ---: |
| 売上高営業利益率 | $150 \div 1{,}000$ | 15% |
| 流動比率 | $500 \div 250$ | 200% |
| 当座比率 | $(200 + 250) \div 250$ | 180% |
| 自己資本比率 | $400 \div 800$ | 50% |
| 固定比率 | $300 \div 400$ | 75% |
| ROE | $70 \div 400$ | 17.5% |
| フリーキャッシュフロー | $120 + (-80)$ | 40 |

ROE を分解すると、売上高当期純利益率 $70 \div 1{,}000 = 7\%$、総資本回転率 $1{,}000 \div 800 = 1.25$ 回、財務レバレッジ $800 \div 400 = 2$ 倍で、
$7\% \times 1.25 \times 2 = 17.5\%$ と一致します。

読み取れること:

- 本業の利益率は 15% あり、経常利益までの落ち込みは小さい（利息の負担は重くない）
- 当期純利益が経常利益より大きく減ったのは、旧システムの除却という臨時の損失のため。来期もくり返すものではない
- 流動比率 200%、自己資本比率 50% で、短期・長期とも安全性に大きな問題は見られない
- 営業キャッシュフローがプラスで、その範囲内で投資と返済をまかなえている

次は、前期の数字や同業他社と比べて、利益率や ROE が上がっているか下がっているかを確かめます。

## 試験対策のポイント

- **ip**: 段階利益の計算（特に営業利益と経常利益の違い）と、貸借対照表の区分（流動・固定、負債・純資産）が頻出です。流動比率など簡単な指標の計算も出ます。
- **fe**: 段階利益の計算方式、ROE・ROA・流動比率・自己資本比率の計算を確実にします。分子と分母を取り違えないことが大切です。
- **ap**: 財務指標による分析（複数の指標の組合せ、ROE の分解）、キャッシュフロー計算書の3区分とフリーキャッシュフローが問われます。
