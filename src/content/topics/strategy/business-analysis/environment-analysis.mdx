外部環境の分析は、自社では変えられない「世の中」と「業界」の状況を整理して、**機会と脅威の候補** を見つける作業です。
社会や経済の大きな流れは **PEST 分析**、業界の競争の構造は **ファイブフォース分析** で見ます。どちらも、後の [SWOT 分析](../swot/) の材料になります。

## 前提となる用語

| 用語 | 意味 |
| --- | --- |
| マクロ環境 | 景気・法律・人口・技術など、業界を問わず多くの企業に影響する大きな環境 |
| ミクロ環境（業界環境） | 顧客・競合・供給業者など、自社の事業に直接関わる環境 |
| 参入障壁 | 新しい企業が業界に入りにくくしている要因（巨額の設備投資、規制、ブランド、販売網など） |
| スイッチングコスト | 顧客が別の製品に乗り換えるときにかかる手間や費用（データの移行、操作の覚え直しなど） |
| 代替品 | 製品は違っても、顧客の同じ欲求を満たせるもの（例: 映画館に対する動画配信） |

## PEST 分析

マクロ環境を **Politics（政治）・Economy（経済）・Society（社会）・Technology（技術）** の4つの観点で洗い出す手法です。
応用情報技術者試験のシラバスでは「マクロ環境分析」として扱われます。

| 観点 | 見るもの | 例 |
| --- | --- | --- |
| Politics（政治） | 法律・規制、税制、政府の政策、補助金 | 規制緩和、個人情報の扱いに関する法改正、補助金制度 |
| Economy（経済） | 景気、物価、為替、金利、賃金水準 | 物価の上昇、円安による輸入コストの増加 |
| Society（社会） | 人口構成、ライフスタイル、価値観、流行 | 少子高齢化、人手不足、健康志向、共働き世帯の増加 |
| Technology（技術） | 新しい技術、その普及の度合い | 生成 AI、スマートフォン決済、IoT |

ポイントは、**数年単位で自社の事業に影響しそうな変化** に絞ることです。一般的な時事問題を並べるだけでは戦略につながりません。
文化的環境（言語・宗教・慣習など）を加えて検討することもあります。

## ファイブフォース分析

M.E.ポーターが提唱した、業界の収益性を決める5つの競争要因です。5つの力が強いほど、業界の企業は利益を上げにくくなります。

<FiveForcesDiagram />

| 競争要因 | 力が強くなる主な状況 |
| --- | --- |
| 業界内の競争（既存競合者同士の敵対関係） | 競合が多い・規模が拮抗している、市場の成長が遅い、差別化しにくい、固定費が高い、撤退しにくい |
| 新規参入の脅威 | 参入障壁が低い（少ない投資で始められる、規制がない、ブランドや販売網がなくても売れる） |
| 代替品の脅威 | 代替品の価格や性能が魅力的、顧客が代替品に乗り換えやすい |
| 買い手の交渉力 | 買い手が大口・少数、スイッチングコストが低い、製品が標準化されていて比べやすい |
| 売り手（供給者）の交渉力 | 供給者が少数、供給される部品や原材料に代わりがない、供給者を変えるコストが高い |

## 実際の進め方

1. **目的と対象を決める** … どの事業・どの市場について、何年先までを見るのかを決めます。「業界」の範囲（例: 予約システム全体か、飲食店向けだけか）で結果が変わるので、最初に言葉にしておきます。
2. **情報を集める** … 官公庁の統計や白書、業界団体の資料、調査会社のレポート、ニュース、そして営業担当者が顧客から聞いている声を集めます。社外の資料だけでなく、現場の情報を入れるのがコツです。
3. **PEST で変化を洗い出す** … 4つの観点ごとに付箋やシートに書き出し、「自社への影響（プラスかマイナスか）」と「影響の大きさ」「起こる確からしさ」を添えます。
4. **ファイブフォースで業界を評価する** … 5つの要因ごとに根拠を書き、力の強さを「強い／中程度／弱い」で評価します。根拠のない評価は議論で覆されやすいので、必ず事実を添えます。
5. **機会・脅威に翻訳する** … 「だから自社にとって何が機会・脅威なのか」を一文で書きます。これが SWOT の O・T になります。

ワークシートは次のような形が使いやすいです。

| 観点 | 変化（事実） | 自社への影響 | 大きさ | 確からしさ | 機会か脅威か |
| --- | --- | --- | --- | --- | --- |
| 社会 | 飲食店の人手不足が続く | 電話応対の省力化需要が増える | 大 | 高 | 機会 |
| … | … | … | … | … | … |

### よくある失敗と対策

| 失敗 | 対策 |
| --- | --- |
| 一般論の羅列で終わる（「AI が進化している」） | 「だから自社の顧客の何が変わるか」まで書く |
| 内部の事情が混ざる（「自社の営業が弱い」） | 自社で変えられることは内部環境に回す |
| 業界の範囲があいまいで評価がぶれる | 最初に対象の顧客・製品の範囲を決めて書いておく |
| 一度作って終わる | 計画の見直しのたびに更新する。環境は変わり続ける |

## 事例

架空の企業 **ツバメ情報システム** の飲食店向け予約・顧客管理 SaaS「ヨヤクル」について、今後3年の外部環境を分析します（数値・状況は架空の設定です）。
業界の範囲は「中小の飲食店向けの予約管理サービス」としました。

### PEST 分析

| 観点 | 変化 | 自社への影響 | 判定 |
| --- | --- | --- | --- |
| 政治 | 中小企業の IT ツール導入を支援する補助金制度がある | 導入費用の負担を下げて提案できる | 機会 |
| 経済 | 食材費・人件費が上がり、飲食店の経営が厳しい | 店の IT 予算が削られる／廃業による解約が増える | 脅威 |
| 経済 | 訪日外国人客が増えている | 多言語での予約受付の需要が増える | 機会 |
| 社会 | 人手不足で、営業中の電話応対が負担になっている | 電話予約を減らせるサービスの需要が増える | 機会 |
| 社会 | 予約の無断キャンセルへの関心が高まっている | 事前決済やキャンセル料の仕組みが求められる | 機会 |
| 技術 | クラウドの普及で、予約システムを安く作れるようになった | 新規参入が増え、価格競争になりやすい | 脅威 |

### 結論（SWOT に渡すもの）

- 業界は **競争・新規参入・代替品の3つの力が強く、価格だけで戦うと利益が出にくい**。価格以外の理由で選ばれる必要がある。
- 機会: 電話応対の省力化需要、多言語予約の需要、無断キャンセル対策への関心、IT 導入の補助金
- 脅威: 大手の低価格・無料プラン、グルメサイトの無料予約機能、飲食店の経営悪化と廃業

この結果は、[3C 分析とバリューチェーン分析](../three-c-and-value-chain/) で内部環境を見たあと、[SWOT 分析](../swot/) でまとめます。

## 試験対策のポイント

- **fe**: ファイブフォースの5つの要因の名前と、事例の記述がどの要因に当たるかが問われます。「代替品」と「新規参入」の区別（同じ製品で入ってくるのが新規参入、別の手段で同じ欲求を満たすのが代替品）に注意します。
- **ap**: どんな状況でその力が強くなるか（参入障壁、スイッチングコスト、供給者の数など）を理由とともに判断する問題や、PEST の4観点への分類が問われます。
