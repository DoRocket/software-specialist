分析で「どこに機会があり、自社に何ができるか」が見えたら、次は **どの方向に伸びるか（成長戦略）** と **競合に対してどう勝つか（競争戦略）** を決めます。
このページでは、そのときに使う代表的な考え方と、[SWOT](../swot/) や [PPM](../ppm/) の結果から戦略を選ぶ手順を扱います。

## 前提となる用語

| 用語 | 意味 |
| --- | --- |
| シナジー効果 | 複数の事業や資源を組み合わせることで、別々に行うより大きな効果が出ること |
| 差別化 | 品質・機能・サービス・ブランドなどで、競合にない価値を顧客に認めてもらうこと |
| 参入障壁 | 新しい企業が市場に入りにくくする要因（[ファイブフォース分析](../environment-analysis/) 参照） |
| 競争優位 | 競合よりも顧客に選ばれ、利益を上げられる状態 |

## アンゾフの成長マトリクス

H.I.アンゾフが提唱した、**製品** と **市場** をそれぞれ「既存」「新規」に分けた4つの成長の方向です（製品・市場マトリクスともいいます）。

| | 既存製品 | 新製品 |
| --- | --- | --- |
| **既存市場** | **市場浸透戦略**: 今の顧客に、今の製品をもっと買ってもらう（利用頻度の向上、競合からの乗換え） | **製品開発戦略**: 今の顧客に、新しい製品を提供する |
| **新市場** | **市場開拓戦略**: 今の製品を、新しい地域・顧客層に売る | **多角化戦略**: 新しい市場に、新しい製品で進出する |

右下に行くほど、自社の経験やノウハウが使えなくなり **リスクが高く** なります。多角化は、既存事業とのシナジーがあるか（技術・販路・ブランドを共有できるか）が成否を分けます。

## ポーターの競争の基本戦略

M.E.ポーターは、競争優位の源泉（低コストか独自性か）と、対象とする市場の広さで、3つの基本戦略を示しました。

| | 低コスト | 差別化（独自性） |
| --- | --- | --- |
| **広い市場** | **コストリーダーシップ戦略**: 業界で最も低いコストを実現し、価格競争力で勝つ | **差別化戦略**: 品質・機能・ブランドなどで独自の価値を出し、高い価格でも選ばれる |
| **狭い市場（特定の地域・顧客層）** | **集中戦略（コスト集中）** | **集中戦略（差別化集中）** |

ポーターは、どれにも徹しきれない「どっちつかず」の状態は利益が出にくいと指摘しています。どれか1つを選び、それに合わせて活動をそろえることが重要です。

## コトラーの競争地位別の戦略

P.コトラーは、市場での地位によって企業を4つに分類し、それぞれがとるべき基本戦略を示しました。

| 地位 | 特徴 | 基本戦略 |
| --- | --- | --- |
| リーダー | 市場シェア首位 | 市場全体の拡大、全方位での対応。チャレンジャーの差別化をまねて無効にする **同質化戦略** |
| チャレンジャー | リーダーを狙う2位以下の有力企業 | リーダーとの差別化で地位の向上を狙う |
| フォロワー | 上位をまねる企業 | 上位企業の模倣で開発コストを抑え、効率よく利益を確保する |
| ニッチャー | 特定の領域に特化する企業 | 特定の市場（すき間）に集中し、その中で独自の地位を築く（**ニッチ戦略**） |

## ブルーオーシャン戦略

W.チャン・キムと R.モボルニュが提唱した、競争の激しい既存市場（レッドオーシャン）で戦うのではなく、**競争のない新しい市場（ブルーオーシャン）** を作り出す考え方です。
業界で当たり前とされている価値の要素を見直し、**取り除く・減らす・増やす・付け加える** の4つの操作で、低コストと差別化を同時に実現することを目指します。

## コアコンピタンスとベンチマーキング

- **コアコンピタンス**（G.ハメルと C.K.プラハラードが提唱）: 競合にまねできない、自社の中核となる能力。複数の事業や製品に展開でき、顧客の価値に貢献するものを指します。
- **ベンチマーキング**: 優良企業（同業に限らず異業種も含む）の優れたやり方（**ベストプラクティス**）と自社を比較し、差を分析して改善する手法です。

## 実際の進め方

1. **出発点を確認する** … SWOT で選んだ戦略オプションと、PPM で決めた事業の方針（育成・維持・収穫・撤退）を並べます。
2. **成長の方向を選ぶ** … アンゾフの4つの方向ごとに候補を書き、リスクと必要な資源を比べます。通常は市場浸透から検討し、足りない分を他の方向で補います。
3. **競争の仕方を選ぶ** … 3つの基本戦略のどれで勝つかを1つ決めます。自社の競争地位（リーダーか、ニッチャーか）も確認し、地位に合った戦い方かを点検します。
4. **やらないことを決める** … 選んだ戦略と矛盾する施策（差別化を選んだのに値下げで対抗する、など）を書き出し、やめます。
5. **核となる能力を確かめる** … 戦略を支えるコアコンピタンスは何か、それをベンチマーキングでどう磨くかを決めます。
6. **目標と指標に落とす** … [バランススコアカード](../balanced-scorecard/) で KPI を設定します。

### よくある失敗と対策

| 失敗 | 対策 |
| --- | --- |
| 4つの成長方向すべてに手を出し、資源が分散する | 優先順位を付け、時期をずらす（1年目は市場浸透、2年目から市場開拓など） |
| 「差別化」と言いながら、実際の施策が値下げ中心 | 選んだ基本戦略と施策の整合を、やらないことのリストで確認する |
| 自社の地位を実際より高く見て、リーダーの戦い方をする | 市場の定義を明確にし、シェアの事実から地位を判断する |
| ベンチマーキングで同業の数字だけを比べる | 改善したい業務が優れている異業種も対象にし、数字の差だけでなくやり方を学ぶ |

## 事例

架空の企業 **ツバメ情報システム** の「ヨヤクル」事業の続きです（数値・状況は架空の設定です）。
PPM で「A県と周辺の中小飲食店に絞って投資し、まずその市場で首位を取る」と決めました。

**成長の方向（アンゾフ）**

| 方向 | 候補 | 判断 |
| --- | --- | --- |
| 市場浸透 | A県の中小飲食店に「導入まるごとパック」と商工会との説明会で導入を増やす（SWOT の SO-1・SO-2） | 1年目の最優先 |
| 製品開発 | 既存の顧客向けに、決済代行と連携した事前決済・多言語予約を追加する（WO-1） | 1年目から開発、2年目に提供 |
| 市場開拓 | ヨヤクルを隣県の飲食店に販売する | A県で首位になってから、3年目に検討 |
| 多角化 | 飲食店向けの食材発注サービスを新たに始める | 自社の強みが生きないので見送り |

**競争の仕方**: 対象をA県と周辺の中小飲食店に絞り、手厚い導入支援で選ばれる **差別化集中** を選びました。
全国で見ればニッチャーの立場なので、大手と同じ全方位の機能競争はしません。「無料プランへの値下げ対抗はしない」「大型チェーン向けの個別開発は受けない」を、やらないことのリストに入れました。

**ブルーオーシャンの4つの操作** で、ヨヤクルの提供価値を組み替えました。

| 取り除く | 減らす | 増やす | 付け加える |
| --- | --- | --- | --- |
| 大型チェーン向けの高度な分析機能 | 料金プランの種類（5種類 → 2種類） | 訪問・電話のサポート、店員向けの説明会 | 補助金の申請支援、無断キャンセル対策の相談 |

**コアコンピタンスとベンチマーキング**: 社内で検討した結果、「IT に不慣れな顧客に寄り添って使い続けてもらう導入・運用支援力」は、ケアノート事業でも継続率の高さを支えていることが分かり、全社のコアコンピタンスと位置付けました。
これを磨くため、継続率の高さで知られる地域の会員制サービス（他業種）の入会後のフォローのやり方を調べてベンチマークとし、導入後 1か月・3か月の訪問を手順に加えました。

## 試験対策のポイント

- **ip**: アンゾフの4つの戦略の区別（製品と市場のどちらが新規か）、ニッチ戦略・同質化戦略・ブルーオーシャン戦略・コアコンピタンス・ベンチマーキングの意味が問われます。
- **fe**: ポーターの3つの基本戦略、コトラーの4つの地位と基本戦略を、事例文から判断する問題が出ます。
- **ap**: シラバスで成長マトリクスの「目的・特徴・手順」が対象です。競争地位と基本戦略の組合せの適否や、分析結果からの戦略の選択を問う問題に備えます。
