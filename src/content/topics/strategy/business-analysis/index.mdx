経営戦略は、企業が目標を達成するために「どの市場で」「どのように競争するか」を定めた長期的な方針です。
戦略を考えるための分析フレームワークは数多くありますが、ばらばらに覚えるより **「何を知りたいときに、どの順番で使うか」** で整理すると、実務でも試験でも使い分けられるようになります。
このページは分野の地図で、各手法の具体的な進め方と事例は下の子トピックで扱います。

## 前提となる用語

| 用語 | 意味 |
| --- | --- |
| 外部環境 | 景気・法規制・技術・顧客・競合など、**自社では変えられない** 自社の外側の状況 |
| 内部環境 | 技術・人材・ブランド・資金・業務の仕組みなど、**自社で変えられる** 自社の内側の状況 |
| 経営資源 | 事業に使う「ヒト・モノ・カネ・情報」。限られているので、どこに配分するかが戦略の中心になる |
| 競争優位 | 競合よりも顧客に選ばれ、利益を上げられる状態。その源泉が何かを分析で突き止める |
| フレームワーク | 考える観点をあらかじめ決めた型。抜け漏れを防ぎ、関係者で同じ言葉で議論できる |

## 戦略の階層

戦略は、企業全体から現場の施策まで階層になっています。分析手法も、どの階層の意思決定に使うかで選びます。

| 階層 | 決めること | 主な手法 |
| --- | --- | --- |
| 企業理念・ビジョン | 何のために存在し、どうなりたいか（MVV: ミッション・ビジョン・バリュー） | — |
| 全社戦略 | どの事業領域（ドメイン）で戦い、事業の組合せと経営資源の配分をどうするか | PPM、アンゾフの成長マトリクス、コアコンピタンス |
| 事業戦略（競争戦略） | 個々の事業が、競合に対してどう勝つか | ファイブフォース、3C、SWOT、ポーターの基本戦略、競争地位別の戦略 |
| 機能別戦略 | マーケティング・開発・人事など、機能ごとに何をするか | 4P/4C、STP（[マーケティング](../marketing/)） |

## 分析の流れ（使う順番）

実務では、おおむね **外部環境 → 内部環境 → 統合 → 戦略立案 → 目標設定** の順に進めます。
先に外部を見るのは、「強み」は市場や顧客にとって意味があるかどうかで決まり、外部の状況が分からないと判断できないからです。

<StrategyFlowMap />

| 段階 | 知りたいこと | 使う手法 | 次の段階に渡すもの |
| --- | --- | --- | --- |
| ① 外部環境 | 社会・経済の大きな変化は何か／業界はもうかりやすいか | [PEST 分析・ファイブフォース分析](environment-analysis/) | 機会・脅威の候補 |
| ② 内部環境 | 顧客は何を求め、競合と比べて自社はどうか／どの活動が価値を生むか／その強みは長続きするか | [3C 分析・バリューチェーン分析・VRIO 分析](three-c-and-value-chain/) | 強み・弱みの候補、成功要因（KSF） |
| ③ 統合 | 強み・弱み・機会・脅威を並べ、組み合わせると何ができるか | [SWOT 分析・クロス SWOT 分析](swot/) | 戦略の選択肢と優先順位 |
| ④ 戦略立案 | 事業の組合せと資源配分／成長の方向／競争の仕方 | [PPM](ppm/)、[成長戦略と競争戦略](growth-and-competitive-strategy/) | 全社戦略・事業戦略 |
| ⑤ 目標と評価 | 戦略が進んでいるかを何で測るか | [バランススコアカード・KPI](balanced-scorecard/) | 目標値、評価の仕組み |

実際には一方通行ではなく、SWOT で「強み」と書いた項目を VRIO で検証し直したり、戦略を決めた後に KPI の結果を見て分析をやり直したりと、行き来しながら精度を上げます。

## 主なフレームワーク一覧

| 手法 | 分析の対象 | 一言でいうと |
| --- | --- | --- |
| PEST 分析 | マクロ環境 | 政治・経済・社会・技術の4つの観点で外部の変化を洗い出す |
| ファイブフォース分析 | 業界の競争環境 | 5つの競争要因で業界の収益性を分析 |
| 3C 分析 | 事業を取り巻く主体 | 顧客・競合・自社を比べて成功要因を探る |
| バリューチェーン分析 | 自社の事業活動 | どの活動で価値（利益）を生んでいるか |
| VRIO 分析 | 自社の経営資源 | 経済的価値・希少性・模倣困難性・組織で、強みが長続きするかを評価 |
| SWOT 分析 | 自社の内部環境と外部環境 | 強み・弱み・機会・脅威の4つに整理し、クロス SWOT で戦略を導く |
| PPM | 自社の事業・製品の組合せ | 市場成長率と相対的市場シェアで4分類し、資金の配分を考える |
| アンゾフの成長マトリクス | 成長の方向 | 製品（既存・新規）×市場（既存・新規）で4つの成長戦略 |
| バランススコアカード | 戦略の実行と評価 | 財務・顧客・業務プロセス・学習と成長の4つの視点で目標と指標を設定 |

## 「他社ではどうしているか」についての注意

フレームワークの使い方は、企業の規模や目的によってさまざまです。
多くの企業に共通して見られるのは、中期経営計画や新規事業の検討のタイミングで、経営企画部門などが中心となり、営業・開発など複数の部門の担当者を集めて分析を行う、というやり方です。
一方で、個々の企業がどの分析をどう行ったかは外部からは分からないことがほとんどで、公表されている「〇〇社の SWOT 分析」の多くは第三者が外から推測したものです。

このため子トピックの事例は、架空の企業 **ツバメ情報システム**（地方都市に本社を置く従業員約150名の IT 企業）を使い、同じ会社で ①〜⑤ を最初から最後まで通して見せます。

| 事業 | 内容 | 売上高 |
| --- | --- | --- |
| ヨヤクル | 飲食店向けの予約・顧客管理 SaaS（数年前に開始） | 6億円 |
| 受託開発 | 地元企業向けの業務システム開発 | 18億円 |
| ケアノート | 介護施設向けの介護記録 SaaS | 8億円 |
| 機器販売・保守 | パソコン・複合機の販売と保守 | 8億円 |

事例の目的は「伸び悩むヨヤクル事業を今後3年でどうするか」を決めることです。
外部環境の分析から始めて、SWOT で戦略の選択肢を出し、PPM で会社全体の中での位置付けを確かめ、成長の方向と競争の仕方を選び、最後に KPI を設定します。

## 試験対策のポイント

- **ip**: 各フレームワークの名前と分析対象の対応が頻出です。SWOT の4要素の分類（内部か外部か）、PPM の4象限の名称と軸を確実に覚えます。
- **fe**: 事例文の記述が SWOT のどの要素か、PPM のどの象限かを判断する問題が出題されます。全社戦略と事業戦略のどちらの話かを区別できるようにします。
- **ap**: 複数の手法を組み合わせた戦略立案や、分析結果からとるべき戦略を選ぶ問題に備えます。各手法の「目的・特徴・手順」がシラバスで問われる対象になっているので、子トピックの「実際の進め方」まで押さえます。
