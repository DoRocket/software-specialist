企業が目的を達成するには、適切な組織で経営資源（ヒト・モノ・カネ・情報）を管理し、データに基づいて業務を分析・改善し、合理的に意思決定する必要があります。

## 経営組織

| 組織形態 | 特徴 |
| --- | --- |
| 職能別組織 | 営業・製造・経理など **機能ごと** に部門を分ける。専門性を高めやすいが、部門間の調整に時間がかかる |
| 事業部制組織 | 製品・地域・顧客ごとに事業部を作り、各事業部が **利益責任** を持つ。意思決定は速いが、機能が重複しやすい |
| マトリックス組織 | 職能と事業（プロジェクト）の2つの軸で構成し、メンバーが **2人の上司** の指示を受ける |
| プロジェクト組織 | 特定の目的のために各部門から人員を集めた **期間限定** の組織 |
| カンパニー制 / 持株会社 | 事業部を社内の独立した会社のように扱う / 株式の保有を通じてグループ会社を管理する |

経営層の役職として、CEO（最高経営責任者）、CIO（最高情報責任者）、CFO（最高財務責任者）などがあります。

### CSR と企業統治

**CSR**（企業の社会的責任）は、企業が利益の追求だけでなく、従業員、顧客、取引先、地域社会、環境などの **ステークホルダ** に対して責任を果たすべきという考え方です。
経営者の活動を監視・規律する仕組みを **コーポレートガバナンス** といいます。

## OR と IE

**OR**（オペレーションズリサーチ）は、線形計画法（制約条件の下で利益最大化・費用最小化を図る）、在庫問題、ゲーム理論などの数理モデルで最適な意思決定を支援する手法です。
**IE**（インダストリアルエンジニアリング）は、作業時間分析やワークサンプリング法などで作業の方法や時間を測定し、生産性を高める手法です。

## QC七つ道具と新QC七つ道具

主に **数値データ** を分析する QC 七つ道具と、主に **言語データ** を整理する新 QC 七つ道具があります。

| QC七つ道具 | 用途 |
| --- | --- |
| パレート図 | 項目を件数の多い順に並べた棒グラフと累積比率の折れ線グラフ。重点的に対策すべき項目を見つける |
| 特性要因図 | 結果（特性）とそれに影響する要因の関係を魚の骨の形で整理する |
| ヒストグラム | データの分布（ばらつき）を柱状図で表す |
| 散布図 | 2つの変数を縦軸と横軸にとって点を打ち、相関関係の有無を見る |
| 管理図 | 時系列のデータを中心線と上下の管理限界線とともに描き、工程が安定しているかを判断する |
| チェックシート | 確認項目や発生件数を記録・集計する |
| 層別 | データを機械別・作業者別などのグループに分けて比較する |

| 新QC七つ道具 | 用途 |
| --- | --- |
| 親和図法 | 断片的な言語データを、意味の近いものどうしでまとめて問題を明確にする |
| 連関図法 | 複雑に絡み合った原因と結果の関係を矢印で結んで整理する |
| 系統図法 | 目的を達成する手段を、目的→手段の階層に展開する |
| マトリックス図法 | 2つの要素の組合せを行と列にとり、関連の有無や強さを整理する |
| マトリックスデータ解析法 | マトリックス図の数値データを解析して整理する（新QC七つ道具で唯一の数値解析） |
| PDPC 法 | 計画の実行過程で起こりうる事態を予測し、対策を事前に検討する |
| アローダイアグラム法 | 作業の順序関係を矢印で表し、日程計画を立てる |

パレート図の考え方を在庫や売上の管理に応用し、品目を重要度で A・B・C に分けて管理の度合いを変える手法を **ABC 分析** といいます。

## 意思決定とデシジョンツリー

**デシジョンツリー**（決定木）は、意思決定の分岐（□）と、確率的に起こる事象の分岐（○）を木構造で表し、各案の **期待値**（金額 × 確率の合計）を比較して最適な案を選ぶ手法です。

### 例題（デシジョンツリー）

**問** 新製品の生産規模を決める。需要が大きくなる確率は 0.6、小さくなる確率は 0.4 である。期待利益が最大になる案はどれか。

| 案 | 需要大のときの利益 | 需要小のときの利益 |
| --- | --- | --- |
| 大規模生産 | 1,000 万円 | −200 万円 |
| 小規模生産 | 500 万円 | 200 万円 |
| 生産しない | 0 万円 | 0 万円 |

**解き方** 各案の期待値を計算します。
大規模生産 = 1,000 × 0.6 + (−200) × 0.4 = 600 − 80 = **520 万円**、
小規模生産 = 500 × 0.6 + 200 × 0.4 = 300 + 80 = 380 万円、生産しない = 0 万円。
期待値が最大の **大規模生産** を選びます。損失の可能性がある点が気になる場合は、最悪の結果が最も良い案を選ぶ **マクシミン原理** という別の判断基準もあります（この場合は小規模生産）。

## 在庫管理と発注方式

| 方式 | 発注のタイミング | 発注量 | 向いている品目 |
| --- | --- | --- | --- |
| 定量発注方式（発注点方式） | 在庫量が **発注点** を下回ったとき | 毎回一定（経済的発注量など） | 需要が安定した重要度の低い品目 |
| 定期発注方式 | **一定の間隔**（毎週、毎月など） | その都度、需要予測と在庫量から計算 | 重要度の高い品目（ABC 分析の A 品目） |

- **発注点** = 1日当たりの平均使用量 × 調達期間（発注から納品までの日数）＋ 安全在庫
- **安全在庫** は、需要のばらつきや納期の遅れによる品切れを防ぐために上乗せする在庫です。
- **経済的発注量（EOQ）** は、発注費用と在庫保管費用の合計が最小になる1回当たりの発注量です（年間需要量 D、1回の発注費用 S、1個当たりの年間保管費用 H のとき √(2DS ÷ H)）。

### 例題（発注点）

**問** ある部品の1日の平均使用量は 20 個、発注から納品までの調達期間は 5 日、安全在庫は 30 個である。発注点は何個か。

**解き方** 発注点 = 20 × 5 + 30 = **130 個** です。納品までの5日間に平均 100 個使っても、安全在庫分が残ります。

## 試験対策のポイント

- **ip**: 組織形態の特徴（特にマトリックス組織、事業部制）、CSR、パレート図・特性要因図・散布図・管理図の用途、デシジョンツリーによる期待値の計算が頻出です。
- **fe**: QC七つ道具と新QC七つ道具の区別、発注点や期待値の計算、定量発注方式と定期発注方式の比較、線形計画法の定式化が問われます。
- **ap**: マクシミン原理・ラプラスの原理など不確実性下の意思決定基準、経済的発注量の計算、管理図による工程の異常判定など、計算と判断を組み合わせた問題に備えます。
