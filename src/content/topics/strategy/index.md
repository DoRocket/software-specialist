ストラテジ分野では、情報システムを使う側である企業の活動について学びます。
ITは経営目標を達成するための手段であり、「企業がどのような戦略をとり、どのようにお金を管理し、どのような法律を守る必要があるか」を理解することで、システムの企画や提案に生かせるようになります。

## 全体像

| テーマ | 主な内容 | 関連する問い |
| --- | --- | --- |
| 経営戦略と分析手法 | SWOT、PPM、バリューチェーン、3C、ファイブフォース | 自社はどの市場でどう戦うか |
| 財務・会計 | 損益計算書、貸借対照表、損益分岐点、減価償却 | 企業の成績と財政状態をどう読み取るか |
| 法務と知的財産 | 著作権、産業財産権、不正アクセス禁止法、個人情報保護法、契約形態 | ITに関わる活動で守るべきルールは何か |
| システム戦略とシステム企画 | 情報システム戦略、EA、BPR、クラウドサービスの活用、調達（RFI/RFP） | 経営戦略を実現する情報システムをどう企画・調達するか |
| マーケティング | 4P/4C、STP、プロダクトライフサイクル、価格戦略、CRM | 顧客に価値をどう届けるか |
| ビジネスインダストリと技術戦略 | e-ビジネス、IoT、AI、フィンテック、MOT・技術ロードマップ | 技術をどう事業に生かすか |
| 企業活動と業務分析 | 経営組織、OR・IE、QC七つ道具、デシジョンツリー、在庫管理 | 業務の問題をどう分析し意思決定するか |

ITパスポート試験ではストラテジ系が出題の大きな割合を占め、基本情報・応用情報でも計算問題（損益分岐点など）や法令の問題が継続して出題されます。

## 学ぶ順序

1. **経営戦略と分析手法** … 各フレームワークが「何を」「どの軸で」分析するかを押さえます。
2. **財務・会計の基礎** … 財務諸表の構造を理解したうえで、損益分岐点と減価償却の計算を練習します。
3. **法務と知的財産** … 権利の種類と保護期間、IT関連の法律、契約形態ごとの責任の違いを整理します。
4. **システム戦略とシステム企画** … 経営戦略を情報システムの企画・調達に落とし込む流れを学びます。
5. **マーケティング** と **ビジネスインダストリと技術戦略** … 市場・顧客への働きかけと、技術を事業に生かす考え方を学びます。
6. **企業活動と業務分析** … 組織の形と、業務改善や意思決定に使う分析手法（QC七つ道具、期待値計算など）を練習します。
