マーケティングは、顧客が求める価値を把握し、製品やサービスとして届け、継続的に選ばれる仕組みを作る活動です。
試験では、「誰に（STP）」「何を・どのように（4P/4C）」売るかを整理する枠組みと、製品の段階や価格設定の考え方、Web を使った手法の用語が問われます。

## STP 分析

| 段階 | 内容 | 例 |
| --- | --- | --- |
| セグメンテーション（Segmentation） | 市場を、地理的・人口統計的（年齢、所得など）・心理的（価値観など）・行動的（購買頻度など）な変数で細分化する | 「20代の一人暮らし」「健康志向の高齢者」 |
| ターゲティング（Targeting） | 細分化した市場から、自社が狙う市場を選ぶ | 「健康志向の高齢者」を主な顧客とする |
| ポジショニング（Positioning） | 競合と比べた自社製品の位置付けを顧客に認識させる | 「手頃な価格で減塩」 |

## 4P と 4C

売り手から見た **4P** と、それを買い手の視点で言い換えた **4C** を対応付けて押さえます。

| 4P（売り手の視点） | 4C（買い手の視点） | 検討する内容 |
| --- | --- | --- |
| Product（製品） | Customer Value（顧客価値） | 品質、機能、デザイン、ブランド |
| Price（価格） | Customer Cost（顧客の負担） | 価格設定、割引、支払条件 |
| Place（流通） | Convenience（利便性） | 販売チャネル、店舗、物流 |
| Promotion（販売促進） | Communication（対話） | 広告、販売促進、広報（パブリシティ） |

流通では、実店舗・EC サイト・アプリなど複数のチャネルを連携させ、どこでも同じように購入できるようにする **オムニチャネル** が重要になっています。
販売促進には、小売店などの流通業者に働きかけて売り込む **プッシュ戦略** と、広告などで消費者の需要を喚起して指名買いを促す **プル戦略** があります。

## プロダクトライフサイクル（PLC）

| 段階 | 市場の状況 | 主な戦略 |
| --- | --- | --- |
| 導入期 | 製品の認知度が低く、売上は小さい。利益はマイナスになりやすい | 製品の認知を高める広告・販売促進 |
| 成長期 | 売上が急増し、競合が参入し始める | ブランドの確立、販売チャネルの拡大 |
| 成熟期 | 売上の伸びが鈍化し、競争が最も激しい | 差別化、シェアの維持、新たな用途の開拓 |
| 衰退期 | 売上・利益が減少する | 撤退や縮小、コストの削減 |

## 価格戦略

| 手法 | 考え方 |
| --- | --- |
| スキミングプライシング | 導入時に高価格を設定し、新しいもの好きの顧客から早期に開発費を回収する |
| ペネトレーションプライシング | 導入時に低価格を設定し、一気に市場シェアを獲得する |
| コストプラス法 | 原価に一定の利益を上乗せして価格を決める |
| ダイナミックプライシング | 需要と供給の状況に応じて価格を変動させる（航空券、宿泊料金など） |
| サブスクリプション | 一定期間の利用に対して定額料金を課す |

## Web・デジタルマーケティング

| 用語 | 意味 |
| --- | --- |
| リスティング広告（検索連動型広告） | 検索キーワードに連動して検索結果に表示される広告 |
| アフィリエイト（成功報酬型広告） | 提携サイトの広告経由で購入などが発生したとき、サイト運営者に報酬を支払う |
| SEO | 検索結果で自社サイトが上位に表示されるよう工夫すること |
| A/B テスト | 2種類のページや広告を比較し、成果の高いほうを採用する |
| CVR（コンバージョン率） | サイトの訪問者のうち、購入などの成果（コンバージョン）に至った割合 |

## CRM と顧客分析

**CRM**（顧客関係管理）は、顧客情報や購買履歴を一元管理し、顧客との長期的な関係を築いて顧客満足度と収益を高める考え方・仕組みです。
顧客一人一人に合わせて働きかける **ワントゥワンマーケティング** を支え、既存顧客の維持を重視します。

**RFM 分析** は、Recency（最終購買日）、Frequency（購買頻度）、Monetary（累計購買金額）の3つの指標で顧客をランク付けし、優良顧客や離反しそうな顧客を見つける手法です。

## 実際の進め方

マーケティングの計画は、おおむね **調べる → 誰に（STP）→ 何を・どのように（4P）→ 測って直す** の順に進めます。

1. **市場と顧客を調べる** … [3C 分析](../business-analysis/three-c-and-value-chain/) で顧客・競合・自社を整理し、市場調査（アンケートなどの質問法、売場での観察法、試験販売などの実験法）や、自社の購買データ（RFM 分析など）で顧客の行動と不満を把握します。
2. **市場を細分化する（セグメンテーション）** … 地理的・人口統計的・心理的・行動的な変数から、ニーズの違いがはっきり表れる変数を選んで分けます。分けたセグメントは「規模や成長性が十分か」「内側ではニーズが似ていて、外側とは違うか」「広告や販路が届くか」「自社の強みが生きるか」で評価します。
3. **狙う市場を選ぶ（ターゲティング）** … 評価の高いセグメントを選びます。ターゲットを具体的な一人の人物像として描いた **ペルソナ** を作ると、関係者の間でイメージがそろいます。
4. **位置付けを決める（ポジショニング）** … 顧客が重視する2つの軸で **ポジショニングマップ** を描き、競合と重ならず、顧客が求める位置を選びます。
5. **4P を一貫させて組み立てる** … 選んだ位置付けに合うように、製品・価格・流通・販売促進を決めます。ペルソナが商品を知ってから買い、使い続けるまでの行動と接点を時系列に並べた **カスタマージャーニーマップ** を描くと、どの接点で何をすべきかが分かります。最後に 4C（買い手の視点）で点検します。
6. **KPI を決めて測り、直す** … CVR、リピート率（リテンション率）などの KPI を決め、A/B テストなどで施策を改善し続けます。

ワークシートは次の形にまとめると、STP と 4P のつながりを確認できます。

| 項目 | 記入すること |
| --- | --- |
| ターゲット（ペルソナ） | 誰の、どんな場面の、どんな困りごとか |
| ポジショニング | 競合と比べて、何で選ばれるか（一文で） |
| Product / Customer Value | 何を提供し、顧客にとってどんな価値になるか |
| Price / Customer Cost | いくらで売り、顧客の負担（価格以外の手間も含む）は妥当か |
| Place / Convenience | どこで買え、顧客にとって手に入れやすいか |
| Promotion / Communication | どう知らせ、顧客とどう対話するか |
| KPI | 何を、いつまでに、どの値にするか |

### よくある失敗と対策

| 失敗 | 対策 |
| --- | --- |
| ターゲットが「20〜60代の男女」のように広すぎる | 困りごとが共通する層に絞り、ペルソナで具体化する |
| ポジショニングの軸が売り手の都合（「高機能」）で、顧客が重視していない | 顧客調査で分かった購買の決め手を軸にする |
| 4P がばらばら（高級志向の製品なのに安売りのチラシで告知する） | ポジショニングの一文に照らして、4つがそろっているか点検する |
| 発売して終わる | KPI を決め、データを見て改善する仕組みを最初から用意する |

## 事例

架空の地域スーパー **マルミ**（同じ市内に 5 店舗）が、平日の夕食向けの「15分夕食キット」（下ごしらえ済みの食材と調味料、レシピのセット）を新たに販売する計画を立てます（数値は架空の設定です）。

**① 調べる**: 会員アプリのアンケートと購買データから、平日 18〜20 時の来店客には「献立を考えて料理する時間がない」という声が多く、惣菜の購入は多いものの「毎日だと手作り感がなくて気が引ける」という不満があることが分かりました。

**② セグメンテーション・③ ターゲティング**

| セグメント | 規模 | ニーズとの合致 | 届きやすさ | 自社の強みが生きるか | 判断 |
| --- | --- | --- | --- | --- | --- |
| 店の近くに住む、子育て中の共働き世帯 | 大 | ◎ 時間がないが手作りしたい | ◎ アプリ会員が多い | ◎ 帰り道に寄れる立地 | **ターゲット** |
| 高齢の単身・夫婦世帯 | 中 | ○ 少量がよい | ○ 店頭・チラシ | ○ | 次の段階で検討 |
| 一人暮らしの学生・若手社会人 | 小 | △ 価格を重視 | △ | △ | 対象外 |

ペルソナ: 「38歳、フルタイム勤務、小学生の子ども2人。平日は 18 時半に帰宅し、19 時半までに夕食を出したい。惣菜に頼る日が続くと後ろめたさを感じる」。

**④ ポジショニング**: 「調理の手間」と「手作り感・地元の食材」を軸にしたマップで、惣菜（手間は最小だが手作り感は低い）、通常の食材購入（手作り感は高いが手間が大きい）の間の、**「15分で作れて、地元の野菜で手作りできる」** という位置を選びました。

**⑤ 4P と 4C の点検**

| 4P | 内容 | 4C で点検 |
| --- | --- | --- |
| Product | 2人前・4人前、週替わり 5 種類、地元農家の野菜を使う | 顧客価値: 平日の時短と、手作りの満足感 |
| Price | 4人前 1,780 円。同じ食材を個別に買うより少し高いが、献立を考える手間と食材の余りがなくなる | 顧客の負担: 価格に加え、考える・買い回る手間が減る |
| Place | 店頭の専用棚に加え、アプリで前日までに予約して 17〜20 時に受取 | 利便性: 帰り道に待たずに受け取れる |
| Promotion | アプリ会員への通知、店頭での試食、レシピカードの配布 | 対話: アプリで感想を集め、メニューの改善に使う |

**⑥ KPI と改善**: 3か月の KPI を「アプリの予約ページからの CVR 5%」「購入者のうち翌月も購入した割合 40%」としました。
最初の1か月、予約ページの訪問 4,000 回に対して予約は 240 件で、CVR は $\dfrac{240}{4{,}000} = 6\%$ でした。
また、アプリの通知文を A/B テストで比べたところ、完成した料理の写真を載せた通知（2,000 人に配信して 80 件の予約、4%）が、価格を強調した通知（2,000 人で 50 件、2.5%）を上回ったため、写真の通知を採用しました。
価格よりも「おいしそうで、自分で作れる」ことが購入の決め手であり、ポジショニングが合っていたことの確認にもなりました。

## 例題

**問** ある Web 広告は 20,000 回表示され、400 回クリックされた。クリックして訪れた利用者のうち 12 人が商品を購入した。クリック率と、訪問者に対する CVR を求めよ。

**解き方** クリック率 $= 400 \div 20{,}000 =$ **2%**。CVR $= 12 \div 400 =$ **3%** です。
CVR の改善には広告から最初に訪れるページの最適化（LPO）、訪問者数の増加には SEO やクリック率の改善、と指標ごとに打ち手が異なります。

## 試験対策のポイント

- **ip**: 4P・4C の対応、PLC の各段階の特徴、スキミングとペネトレーションの違い、リスティング広告・アフィリエイト・SEO などの用語、RFM 分析が頻出です。
- **fe**: STP の各段階の判断、PLC の段階に応じた戦略の選択、事例に当てはまる価格戦略やマーケティング手法を選ぶ問題が出題されます。
- **ap**: CX（顧客体験）やサービスデザインを含め、マーケティング施策とそれを支える情報システム（CRM など）を組み合わせて考える問題に備えます。
